Notice: Stuttering Issue Following Ver. 1.106.0 Update

2026-05-28

Hello, this is Project Moon.

We have identified an issue where, following the May 28th, 2026 Scheduled Update, persistent stuttering issues are observed in-game.

[ Suspected Cause ]
With the Ver. 1.106.0 Update, the game development engine has changed, and some of the preexisting system that converts Limbus Company characters' Skills, Coins, and Buff effects may have become incompatible with the updated game engine, causing the stuttering issue.

Primary sources of stuttering reports have been identified in the following areas:
- Moving between nodes in the Mirror Dungeon
- Making choices and running Skill checks in Mirror Dungeon Choice Events
- Making purchases in Mirror Dungeon shops
- Selecting Combat Encounters and viewing the pre-battle enemy info UI (Refraction Railway, Story Combat Encounters, Mirror Dungeon Combat Encounters, etc.)

[ Issue Fix ]
We have identified, in areas affected by stuttering, the specific logic that requires optimization. We have made the necessary corrections and are currently running tests to ensure its stability.

[Fix Schedule]
We are working to deploy a version that resolves the stuttering issue as part of the Jun. 4th Scheduled Update.
If the work is completed sooner, we will deploy the fix on the Steam platform first, as it does not require a separate review process.

We sincerely apologize for the inconvenience.
