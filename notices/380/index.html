Bug Fixes & Improvements

▶ Adjusted Sinner Don Quixote's employee card image resource visible in Theater - Identity Stories

▶ Fixed an issue where, in Mirror Dungeon Super shops, attempting to Fuse for a Fusion Gift with sub-Fusion ingredients E.G.O Gifts shows an abnormal Fusion Forecast
E.g.) When A+B=C / C+D+E=F,
- Before: Fusing A+B+D+E shows a 'Random' Forecast
- After: Fusing A+B+D+E shows 'F' as the Forecast

▶ Fixed an issue where, in the Mirror Dungeon Theme Pack 'LCB Regular Check-up', a Choice Event that does not fit the Theme Pack could occur
※ We identified an issue where 'Decamillennial Hearthflame' E.G.O Gift, which appears only in MD Hard, can be obtained in MD Normal as well. Because LCB Regular Check-up is available in both Normal and Hard difficulties, we will be eliminating the Choice Event from the said Theme Pack entirely. However, even after this change, you can still obtain the 'Decamillennial Hearthflame' E.G.O Gift from Hard Difficulty via Shop purchases, Rewards, or Fusions.

▶ Fixed an issue where certain E.G.O Gifts that 'Inflict Burn at next turn start' inflicts Burn when retrying a Stage.
※ Relevant E.G.O Gifts: Charred Disk, Purloined Flame

▶ Fixed an issue where using Lobotomy E.G.O::Magic Bullet Outis' Support Passive effect does not activate when using an E.G.O via the SUPERBIA Sapling of Light ability

▶ Fixed an issue where, in Theater - Identity Stories menu, Animated Identity Illustration's VFX could linger when switching to different screens

▶ Adjusted the pop-up text box description that appears when the player hasn't Deployed any Sinners in Chain Battle Stages

▶ (EN Only) Fixed various typos and grammatical errors
※ Parts that were worked on:
1. Grammatical errors and minor typos in Story cutscenes & Choice Events in Stage 6-48
2. Skin Prophet Choice Event
3. An issue where the name of Kurokumo Clan Wakashu Rodion's Skill 1 changed upon Uptying her to Tier 4

▶ (Custom TL Only) Optimization progress made
※ Changes:
1. Gave highest load priority to the font used for Custom Translation
2. Addressed the FPS drop issue when playing with Custom Translation
3. Improved the Loclization Text patch download logic
