Bug Fixes & Improvements

▶ Fixed an issue where, when a Skill is Discarded under certain conditions, the Discarded Skill's rank was considered higher than its actual rank, providing additional effects or Stacks
※ Relevant Effect (1) : Dieci South Section 4 Hong Lu's Passive
"Peering Through a Key" allowed for Insight to be gained beyond 3 Stacks
※ Relevant Effect (2) : Dieci South Section 4 Yi Sang's Support Passive
"Reviewed Knowledge" and Dieci South Section 4 Director Meursault's
Support Passive "Diligent Learning" allowed for Shield to be gained beyond 15% of their respective max HP

▶ Fixed an issue where The Index Proxy - Effloresced E.G.O::Procuration
Don Quixote's physical location on the field did not change depending on Speed in the same turn she gains "Shin (心) - Procuration"
- Before : The unit's placement based on its Speed was decided first, then the unit gained Speed from "Shin (心) - Procuration"
- After : The unit's placement based on its Speed is decided after the unit gains Speed from "Shin (心) - Procuration"

▶ Fixed an issue where a certain enemy in Canto 9 did not activate its Passive effects upon using a Skill
※ Relevant Skill : The Formless Cut [無形斬]'s effect "[Clash Lose]
Damage dealt by this Skill cannot Stagger the target"
- Before : Even after the enemy unit lost the Clash, the "Afterimage
Reverberation" Passive "On Hit with this unit's Coin, deal Slash damage
(damage from this effect cannot Stagger target)" activated and clashed with the Skill's effect, deactivating both effects.
- After : Both effects activating simultaneously no longer disables the anti-Stagger effect

▶ Fixed an issue where a certain enemy in Canto 9 had a Skill that broke Unbreakable Coins
※ Relevant Skill : Wrapping Coil

▶ Fixed an issue where a certain Skill used by an ally unit featured in Canto 9 activated incorrectly
※ Gain Base Power based on target's Bleed and Tremor
- Before : Gained Base Power based on target's Burn and Tremor instead
- After : Gain Base Power based on target's Bleed and Tremor, as intended

▶ Fixed an issue where Thread Luxcavation #5 (Gloom)'s
Choice Event appeared as Mirror Dungeon Choice Events

▶ Fixed an issue where an ally unit featured in Canto 9 was missing certain lines that were supposed to trigger with Skill use

▶ Fixed an issue where certain Skill names were cut off in the in-combat Skill information UI

▶ Fixed an issue where, when viewing the extraction history from the extraction menu, the Announcer images obtained via Yisang Exchange would appear cut off

▶ Fixed an issue where certain text visuals in Mirror Dungeon 6's Projection Rate reward would show up over the other overlays on the bottom of the screen

▶ Fixed an issue where clearing a Stage for the first time did not automatically move the player to the next playable Stage

▶ Fixed an issue where Jeong's Office Rep. Ishmael's
Skill 3's Coin VFX did not load correctly

▶ Fixed an issue where certain illustrations visible from the "Drive"
tab did not match the illustrations in the "Theater" tab

▶ Fixed an issue where, in Canto 9, certain background SFX could be adjusted with the BGM slider instead

▶ Fixed an issue where Meursault E.G.O "Pursuance"
did not load certain VFX elements

▶ Adjusted the game so that, if all Sinners are killed at the same time as the enemies are, the battle results will now count that as a victory
※ This rule used to apply only in the Refraction Railway, but it has now been expanded to all Stages.

▶ Fixed an issue where, when viewing certain information windows, the SP value text would appear over the effects list window

▶ Fixed an issue where, in certain pre-Canto 9 stories, certain characters' story sprites did not load correctly

▶ (EN Only) Fixed an issue where a certain Canto 9 character had an incorrect name in its combat Encounter

▶ (JP Only) Fixed an issue where a certain Canto 9 character had an incorrect name

▶ Fixed an issue where, in Main Story Stage 9-18, the incorrect Announcer voiceline would play when a certain enemy uses a certain Skill
- Before : Announcer voice for "Danger" played
- After : Announcer voice for "Powerful Enemy Skill Warning" plays
