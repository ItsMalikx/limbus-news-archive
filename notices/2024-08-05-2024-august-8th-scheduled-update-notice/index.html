Major Changes

1. Added arrows underneath HP Bars for better Stagger Threshold visibility

3. Adjusted Identity Level Up Popup UI placements

4. Added Trait Keywords for each unit when viewing their Detailed Information

5. Clarified activation conditions for certain E.G.O Gifts with conditions that require a certain number of Identities from a specific faction/condition

Bug Fixes & Improvements

▶ Stagger+ & Stagger++ are now visible for enemies in Focused Encounters as well

▶ Adjusted Stagger Threshold display for when the Stagger Threshold goes below 0 HP due to effects such as lowering one's Stagger Threshold: Stagger Threshold below 0 will no longer be visible
※ In the Detailed Information window, the Stagger Threshold value will be displayed as (-).

▶ Fixed an issue where one of the Skills present in Stage 6-45 showed multiple Coin effects, despite it being a single Coin effect

▶ Fixed an issue with Abnormality - Pink Shoes Combat Encounter Choice event
(1) Fixed an issue where the enemy state was maintained, despite the successful event choice stating otherwise
(2) Fixed an issue where the Choice event appeared at an incorrect timing for the Thread Luxcavation encounter

▶ Addressed an issue where losing HP beyond the Stagger Threshold due to 'Lose HP' effect in Skills caused units to get Staggered: this will no longer occur
(1) Affected Identity & E.G.O Skills
Ishmael E.G.O - Ardor Blossom Star (Corrosion) / Shi South Section 5 Heathcliff - Counter
(2) Affected Enemy Skills
Golden Fruit / Poison Spray / Pained Writhing / Pained Strugger / Delicious Crab Guts!

▶ Fixed an issue where incorrect resources would load for certain Mirror Dungeon / Combat Encounter Stages

▶ Fixed an issue where the Mirror Dungeon Passive - Pallidification did not work as intended
- Before : The Passive activation condition counted self as well
- After : The Passive activation condition no longer counts self, as written in the description text

▶ Fixed an issue where incorrect values were displayed for failing the second Choice in Mirror Dungeon / Abnormality - Spiral of Contempt / Choice Event
- Before : The Sinner who failed the check takes 25 HP damage and 15 SP damage!
- After : The Sinner who failed the check takes 12 HP damage and 8 SP damage!

▶ Adjusted names of certain E.G.O Gift activation subjects
※ Affected E.G.O Gifts : Nagel und Hammer Scriptures, Wholeness
- Before : ~ from N Corp.
- After : ~ is an N Corp. Fanatic

▶ (EN Only) Adjusted the translation for 'N Corp. Fanatic(s)' in several descriptions
- Before : ~an ally from N Corp. / ~if the ally is from N Corp.
- After : N Corp. Fanatic

※ Affected Descriptions
- Keyword - Gaze(N Corp.)
- The One Who Grips Faust - Combat and Support Passives
- N Corp. Großhammer Meursault - Support Passive
- N Corp. Kleinhammer Heathcliff - Combat Passive

▶ Adjusted starting colors of the ring in the scene that plays when obtaining E.G.O for the first time
- Before : Bronze color
- After : Dark blue color
