    Notice: Server Error Fixes & Mirror Dungeon Improvements

    May 2, 2024
    Mirror DungeonBalance

    Hello,
    This is Project Moon.

    In this notice, we would like to inform you regarding the server errors that have occurred after the May 2nd 12:00 (KST) Scheduled Update, and upcoming improvements to the Mirror Dungeon.

    1. Server Error Fixes

    After the May 2nd 12:00 (KST) Scheduled Update, we identified an issue where an abnormal frequency of server errors prevented players from progressing through the game normally. This issue has now been corrected.

    Over 100,000 server login requests were made immediately after the maintenance completion, which caused the server system to overload and malfunction. This was the cause of the in-game server error popup messages.
    We have taken temporary measures to stabilize the server.

    Please refer to the following for more details.

    <Cause>

    - Abrupt rise in login attempts within a short span of time
    - The sudden rise in login attempts sent a relatively large amount of data requests to the server
    - The amount of data was too much for the server to process, causing the systems to overload and malfunction

    <Solution>

    The following functions have been temporarily limited to stabilize the server.
    - Temporarily disabled Account deletion
    - Temporarily deleted the notification function for new Friend requests in the main UI (by the user banner on the bottom left side of the screen)
    We will monitor the server systems for a while before enabling the above functions again.
    We will inform you via an additional notice regarding the above measures.

    <Future measures>

    - We plan to conduct hardware stabilization and logic optimization work so that the server system will function normally even with multiple concentrated requests.

    We sincerely apologize for the inconvenience.

    2. Mirror Dungeon Improvements

    We are closely monitoring the Managers' opinions regarding the difficulty of Mirror Dungeon - Mirror of the Wuthering.
    Several adjustments, including balancing adjustments, will be deployed to the Mirror Dungeon after continued observation of your experiences.
    We will inform you of the Mirror Dungeon improvements via a notice.

    Our intent in planning this Mirror Dungeon was to slowly ease the difficulty as more and more Starter Buffs are unlocked, which would eventually lead to a similar level of difficulty and playtimes.
    As we have informed you via our previous notice, this Mirror Dungeon may feel more difficult compared to the previous Mirror Dungeon due to the loss of access to the following modifiers: Types of E.G.O Gifts, Numbers, Enhancement Levels, Owned Cost, and Damage Dealt.

    However, we did notice that several enemies that appear in the earlier stages of the Dungeon have abnormally high HP, so their HP will be adjusted via a hotfix.
    This issue occurred because certain enemies from other content, such as Refraction Railway, did not have their HP scaling applied to them in the process; this led to their HP being higher than it should be at that point in the Mirror Dungeon.
    We apologize for the troubles the higher enemy HP may have caused in your Mirror Dungeon experience.
    We will notify you via an additional notice as soon as it is deployed.

    An additional notice will be posted later today regarding additional changes that will be deployed to the Mirror Dungeon.
    We sincerely apologize for causing these balancing issues and complications with every Mirror Dungeon update.
    We will make sure to improve these issues so that you will have a more positive experience with our content.
