Greetings, Dear Manager.

The server will enter scheduled maintenance from 10:00 [AM] through 12:00 [PM] on Jun. 11th, 2026 (KST).

Please make note of the maintenance schedule; we recommend that you refrain from entering combat or making in-app purchases and close the application before maintenance begins so that no data is lost.

Please refer below for details about the update.

Stabilization Regarding Issues Occurring After the 5/28 Unity Version Upgrade

We have completed our investigation into the issues affecting certain mobile devices following the May 28th Scheduled Update. Stabilization will be deployed with the June 11th Scheduled Update.

[Stabilization Details]

※ Fixed an issue where the game would freeze or crash upon entering combat
- We have confirmed that a post-processing error occurs on certain devices that do not support R32_Sfloat textures.
- In light of this, we have modified the logic code so that post-processing effects will not be applied on devices that do not support the relevant texture format.

※ Additional Stabilization Following the Unity Version Upgrade
- Additional system stabilization will be carried out with the Ver. 1.107.0 Update on June 11.
- We have developed a fix to alleviate crashing issues and optimize resource-related processing so that Managers may enjoy a more stable gameplay experience on mobile devices.
- However, due to unavoidable changes made to certain resources during this process, an additional resource download is required.
- As stabilized resources will be redownloaded on each platform, we kindly ask Managers to use a Wi-Fi connection to ensure stable app installation and reduce data usage. Download sizes are as follows:

Steam: Approx. 2.8GB
Android (AOS): Approx. 1.6GB
iOS: Approx. 1.5GB

※ Regarding the previously announced follow-up measures, we will inform you via a separate notice once all issues have been fully resolved to facilitate normal gameplay.

Once again, we sincerely apologize to all Managers for the inconvenience.
