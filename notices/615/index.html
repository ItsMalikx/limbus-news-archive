Bug Fixes and Improvements

► Additional fix for crashes upon entering battles on certain devices
※ The system has been adjusted so that devices equipped with Mali-G610, Mali-G710, and Mali-G715 series GPUs run on "GLES" instead of "Vulkan" for the Graphics API upon game launch.
※ Should this issue persist on your device even after the Jun. 25th Scheduled Update, please provide your device model name, OS version, and other relevant details to our Customer Support so that we may further check the affected GPU.

► Fixed an issue where the Skill 2 "Amoral Enactment" of "The One Who Shall Grip Sinclair" at Uptie Tier 2 would function differently from intended
- Before: The Power value of Coin 1 was applied as -1
- After: The Power value of Coin 1 has been corrected to -3 to match the text

► (Steam) Fixed an issue where the size of the in-game cursor icon could vary depending on the custom resolution set by the user

► Fixed an issue where some speech bubbles would not be displayed when "LCD OSIR Team Ishmael" uses Skill 3 "Lucent Rippling Flame"

► Fixed an issue where, in certain situations, "Blade Lineage Mentor Meursault" would display unnatural skill motions when using "To Claim Their Bones" while projecting "A Moonlit Farewell to Home" Façade

► Fixed an issue where the placement of Assist Units featured in certain Stages of Chapter 9.5 "Mnestic Experience" would not function as intended
- Before: Assist Units and Sinners were arranged in a mixed order depending on the Assist Units' Speed
- After: Assist Units will now always be placed in the front regardless of their Speed

► Fixed an issue where the "Tremor Burst" typography would not appear when "Tremor Burst" occurred due to certain effects
※ The actual "Tremor Burst" effect is functioning normally; only the missing typography issue has been fixed.

► Fixed an issue where, when entering "Reflectrial][lairtcelfeR" immediately after launching the game, the enemy observation log would be unavailable for viewing even though the same enemy had been defeated in another battle content

► Fixed an issue where, in certain situations in "Reflectrial][lairtcelfeR", the "Limited Rewards - Identity Training Ticket III" would intermittently fail to load into the UI

► Fixed an issue where related hotkeys would not function when viewing the Inventory screen or the E.G.O Shard Crate usage pop-up UI in certain situations

► Fixed an issue where, when transitioning screens through "Shard::Thread Exchange" after entering "Reflectrial][lairtcelfeR" via the Chapter 9.5 "Mnestic Experience" event screen, unintended effects would occur

► Fixed an issue where SD Spine motions would not function smoothly when hovering the cursor over an enemy Skill Slot on the combat screen

► Fixed an issue where SD motions would display differently from intended when hovering the cursor over certain Skills used by the boss unit appearing in Chapter 9.5 "Twining Threads"

► Fixed an issue where portrait images would display abnormally when Passives are activated in certain situations during combat

Known Issues
