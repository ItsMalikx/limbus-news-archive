Fix for an issue where "can gain up to N per turn" effects were applied differently than intended in certain situations

※ We will explain using The Blade of House of Spiders Ryōshū's "Dihui Star's Blade" as an example.

[Example Condition]

1. The unit has 67 Stacks of "Dihui Star's Blade"
2. The unit attempts to gain 20 "Dihui Star's Blade" by using the "Slay the Heavens - Tiansha" Skill (this will cause the unit to gain only 3 Stacks of "Dihui Star's Blade", as gaining any more would exceed its max cap)
3. The unit consumes 50 Stacks of "Dihui Star's Blade" by using "Rend Space - Echoshear"
4. The unit attempts to gain an additional 15 Stacks of "Dihui Star's Blade" by using "Rend Space"

- Before:
- When gaining a buff through Skills and other means, if the amount gained exceeded the maximum cap, per-turn limit was calculated based on the total "Stacks attempted to be gained," instead of "Stacks actually gained."
- In the example above, the game treated all 20 Stacks from Step 2 as having been gained. As a result, in Step 4, only 5 Stacks were gained.

- After:
- This will be fixed so that even if the Stacks gained exceeds the maximum cap, only the "amount actually gained" will count toward the per-turn gain limit.
- As a result, buffs can be additionally gained up to the remaining per-turn gain limit.
- In regards to the example above, only the 3 "Dihui Star's Blade" actually gained in Step 2 will be counted toward the cap, allowing all 15 "Dihui Star's Blade" to be gained in Step 4.

Bug Fixes & Improvements

▶ Fixed an issue where some effects of Lobotomy E.G.O::Faint Aroma & Solitude Ryōshū's Passive, "A Void that Cannot be Filled", functioned differently than intended
→ Related effect: At 1+ Bullet - Solitude, if the enemy has less than -40 SP or is Staggered at this unit or an ally's Attack End, use "Bang. Bang." as an Unopposed Attack (once per turn)
- Before: The Passive effect would also activate at the Attack End of Assist Units.
- After: The Passive effect will no longer activate at the Attack End of Assist Units.

▶ Fixed an issue where certain effects did not activate when inflicting "The Living" or "The Departed" using the Corrosion Skill of Solemn Lament Gregor E.G.O.
→ Relevant "Butterfly" effect: No external effects can raise the amount of Butterfly inflicted. "Inflict additional Sinking" effects inflict additional Sinking instead of additional Butterfly.
→ Relevant specific effect: Increase the amount of Burn, Bleed, Rupture, Sinking, or Tremor inflicted by +1 (including 'Unique Status Effects')
- Before: When the E.G.O Corrosion Skill was used while the unit had "Inflict additional Sinking" effects, this unit would not inflict additional Sinking that it was supposed to, as per the Butterfly effect's description
- After: When the E.G.O Corrosion Skill was used while the unit had "Inflict additional Sinking" effects, additional Sinking will now be applied instead of additional Butterfly

※ Lobotomy E.G.O::Solemn Lament Yi Sang and the Awakening Skill of Solemn Lament Gregor E.G.O are functioning normally. Only the Corrosion Skill of Solemn Lament Gregor E.G.O will be fixed.

▶ Fixed an issue where the floor tiles in Stage 9-42 were arranged differently than intended

▶ Fixed an issue where the related typography UI would not be displayed even when Blade Lineage Salsu Meursault's Support Passive, "Swordplay of the Homeland", was activated
※ The Support Passive itself is functioning normally; only the missing typography UI will be fixed.
