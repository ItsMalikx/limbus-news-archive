Notice: Ver. 1.107.1 Known Issues and Hotfix ETA

2026-06-18

Hello. This is Project Moon.

We would like to inform you of the known issues identified after the Scheduled Update on Jun. 18th, 2026, along with the hotfix schedule and detailed information.

Please refer below for more information.

[ To-be Hotfixed ]
▶ Fixed an issue where the background color would display abnormally during the Skill animations of certain Identities in specific Encounters.

[ Hotfix ETA ]
- Jun. 18th (Thu) 20:00 (KST)
- There may be a delay of approximately 10 minutes.

※ The Hotfix will be deployed upon restarting the game, and does not require a separate client update. However, please note that additional in-game downloads may occur.

[ Issues to be resolved with a Scheduled Update ]
▶ An issue where, in certain situations in Reflectrial][lairtcelfeR, the "Limited Rewards - Identity Training Ticket III" would intermittently fail to load into the UI
- Upon further investigation, we have confirmed that Reward Exchange and remaining quantities are all functioning normally, but the UI for the relevant currency may intermittently fail to appear.
- This issue occurred due to insufficient exception handling in the system regarding the difference in the number of items between "Standard Rewards" and "Limited Rewards." This issue will be fixed with the upcoming Scheduled Update.
- Should this issue occur during your gameplay session, please check again after taking one of the following measures: enter a combat Encounter, enter a story scene, or trigger a loading scene.

[ Additional Info Regarding Crashes Upon Entering Battles on Certain Devices ]
Through today's Ver. 1.107.1 update, the system has been adjusted so that devices equipped with Mali-G57 and Mali-G68 series GPUs run on "GLES" instead of "Vulkan" for the Graphics API upon game launch.

We have confirmed that the issue has been resolved for the devices listed above; however, it persists in other environments that do not use those GPUs.

1) Android Devices
- Affected devices and environments: Devices using Qualcomm (Adreno 720), MediaTek (Mali-G610), and several other GPUs, including Mali-G710 and Immortalis-G715.
We have additionally confirmed that the game application fails to run in the environments listed above, and we plan to improve the Graphics API filtering logic to address the issue.

Presently, our ultimate goal is to overhaul the system so that the Graphics API is automatically optimized for the device environment upon game launch.

2) iOS Devices
- Relevant Devices: iPhone 13, iPhone SE 3rd gen., iPhone 12 mini, iPhone 12, etc.
- Following the Unity version upgrade in Ver. 1.106.0, the game application's overall memory usage has increased. We have confirmed that crashes are occurring in the affected device environments due to insufficient available memory resources.

To stabilize the game's operating environment, we are currently analyzing the high-memory-usage components in our game and collaborating with Unity's technical support team to identify optimizable items related to this issue.

We will do our utmost to optimize the game as quickly as possible and provide our Managers with a smooth gameplay experience.

We sincerely apologize for the inconvenience.
