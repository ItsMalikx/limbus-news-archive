Notice: Known Issues Ver. 1.85.0 Updated Aug. 28th

August 28, 2025

Hello, this is Project Moon.

We would like to inform you about the issues that occurred in Version 1.85.0, updated Aug. 28th.

Please continue reading for more information.

[ Known Issues ]

- An issue where Kurokumo Clan Wakashu Ryoshu's Skill 3 "Lenticular Swirl" animation does not work correctly, preventing game progression.

[ Cause ]

- While working on multi-targeting attack cutscenes, we accidentally adjusted logic regarding "Lenticular Rend".

[ Solution ]

- Revert the "Lenticular Rend" Skill Logic

Please refrain from using the [Kurokumo Clan Wakashu Ryoshu] Identity until this issue is resolved.

We'll be sure to inform you via a future Notice as soon as this issue is resolved.

We sincerely apologize for the inconvenience.
