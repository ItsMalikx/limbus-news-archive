Bug Fixes & Improvements

▶ Adjusted the conditions for determining the Staggered state
- Before : Any attempt to adjust the unit's HP that results in a lower HP than before while under the Stagger Threshold causes Stagger
- After : Staggered state activates only when the unit actually takes 'HP damage' while under the Stagger Threshold

▶ Fixed an issue where Lobotomy E.G.O::Red Eyes & Penitence Ryōshū was missing certain animation frames for 'Skullbuster' depending on the Red Eyes Stack

▶ Improved the description text for 'Curse' effect so that its activation timing becomes clearer
- Before : Turn End: Gain one of the following, then reduce this effect’s Count by 1. 1 Attack Power Down/1 Defense Power Down/2 Offense Level Down/2 Defense Level Down.
- After : Turn End: Next turn, randomly gain one of the following, then reduce this effect’s Count by 1. 1 Attack Power Down/1 Defense Power Down/2 Offense Level Down/2 Defense Level Down.

※ The actual effects of 'Curse' wasn't changed.
When we first wrote the description for 'Curse', we believed that 'Turn End:' conditional implied that it would apply next turn; however, as we were working on our new E.G.O, we realized that the lack of clear activation timing could cause confusion in our users, so we have decided to change the description.

▶ Effect(Keyword) description text tooltip additional improvements
(1) Tooltip display UX Changed
※ Affected UI : Skill Descriptions when viewing Detailed Information, E.G.O Gift descriptions
- Before : Long-pressing the keyword would show the tooltip
- After : Tapping the keyword shows the tooltip

(2) Added an auto-scroll function to active effects tooltip descriptions that are too long to fit into a text box

(3) Added an auto-scroll function to tooltips in Skill descriptions that are too long to fit into a text box

▶ Adjusted the UI to add an auto-scroll function to Combat & Support Passives that are too long to fit into a text box in Combat UI

▶ Adjusted Sinner Loadout / ID & E.G.O arrangement functionality
(1) Common
- Fixed an issue where the arrow indicating ascending/descending order appeared opposite of what they were supposed to represent
- (EN Only) Changed a certain arrangement category name
※ "Order of Identities/E.G.O Obtained" was changed from 'Hire Date' to 'Recent'

(2) Identities
- Fixed an issue where the [Recent] category did not work in certain content Loadout Menus
- Eliminated the [Recent] category when viewing the list of Support Units
- Separated the save states for player's Identity List & Identity List with Support Units

(3) E.G.O
- Fixed an issue where the [Name] category does not work as intended
- Fixed an issue where viewing the list in ascending order of [Sin Resist] category, the arrangement would malfunction
- Added [Recent] category

▶ Fixed an issue where results for certain Choice Events for the Abnormality 'You Want to Get Beat? Hurtily?' has a delayed activation timing
※ Relevant warning text : Go for the Big One!
