Bug Fixes & Improvements
------------------------

► Fixed an issue where Cinq East Section 3 Don Quixote's Defense Skill effect does not activate after the first evade
※ Relevant Effect: If this unit's Speed is faster than the target's, gain +1 Coin Power for every 2 Speed difference (max 2)

► Adjusted the description for The Middle Little Sister Don Quixote's Counter Skill 'Multifold Retribution'
- Before: [Combat Start] If at 6+ Envy A-Reson including this Skill, use 'A Just Vengeance' as Counter.
- After: [Combat Start] At 6+ sum of Envy A-Resons.(does not need to be consecutive), use 'A Just Vengeance' as Counter.
※ As this Identity has been out for a while, we decided that the way her Counter Skill currently functions has been solidified as how this character is supposed to function. Also, adjusting the functions to match the description means that this Identity will be weakened. Taking this into account, we intend to make an exception this time to change the description to match the function, as opposed to our usual policy(of changing the function to match the description).

► Fixed an issue where, in Stage 7.5-25, a certain Skill cannot be clashed against
※ Relevant Skill: Night in the Backstreets

► Fixed an issue where, when the Enkephalin Module recharge pop-up window appears when attempting to claim the rewards in the Lost & Found menu of Refraction Railway, the UI malfunctioned under certain circumstances

► Fixed an issue where a choice hint text does not match the actual results in a Choice Event present in the Mirror of the Dreaming Theme Pack - Nocturnal Sweeping
