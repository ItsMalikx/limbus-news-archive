    Notice: Coupon Code Input Website Open

    May 1, 2024
    Rewards

    Greetings, dear Manager.

    The Coupon Code input website will open starting May 2nd, 12:00 (KST).

    Coupon Exchange

    Game UID
    Enter Game UID

    Coupon Code
    Enter Coupon Code

    Confirm

    ◆ Coupons are always combinations of upper-case English alphabets and numbers.
    ◆ No same coupon can be registered more than once for the same account.
    ◆ Coupons past their expiry date cannot be registered.
    ◆ Repeated coupon code input failure within a short timeframe may restrict coupon code for a set amount of time.

    Link: https://coupon.limbuscompany.site

    ▶ How to Use
    1. Start the game, then view your UID in the in-game lobby
    2. Input your UID and coupon code on the Coupon Code input website

    Once you have completed the above steps, you will receive your coupon rewards via the in-game mailbox with the message
    "Coupon exchanged successfully. Please check your mailbox."

    If there has been an error, the following messages will be displayed instead.

    - If the coupon code has already been claimed:
    "This coupon has already been claimed."
    - If there is an issue with the coupon code: "This coupon is invalid."
    - If the UID does not exist: "Game UID does not exist."
    - If the coupon is expired: "This coupon is expired."
    - If there are repeated coupon input failures within a short timeframe: "Repeated coupon code input failure. Coupon input restricted. Please restart after the time indicated below."

    If you have any issues with your coupon input, please message us at limbussupport@projmoon.com, and we will provide support.

    Thank You.
