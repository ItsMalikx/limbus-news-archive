Notice: The Middle Apprentice Ishmael Def. Skill Error Fixed

January 29, 2026

Hello, this is Project Moon.

"The Middle Apprentice Ishmael Defense Skill Error," which we shared on Jan. 27th, has been resolved with the Jan. 29th Scheduled Update.

Please continue reading for more information.

[ Error Fix Details ]

► The Middle Apprentice Ishmael Defense Skill Error Fixed
※ Relevant Effects (At Uptie 4)
1. [Combat Start] At 6+ sum of Envy A-Reson., use "Violet~ Breaking Slam" as Counter (activates 2 times per turn)
2. [Combat Start] Gain 25% of missing HP as Shield (once per turn)

- Before: The Identity did not gain Shield when the Defense Skill was switched with "Violet~ Breaking Slam" Counter
- After: The Identity will now gain Shield even when the Defense Skill switches with "Violet~ Breaking Slam" Counter

※ As we shared in our previous notice, for the sake of consistency between Identities with similar mechanisms, we made an adjustment to this Identity so that its Counter Skill will still gain Shield HP even when it is switched.

Thank you.
