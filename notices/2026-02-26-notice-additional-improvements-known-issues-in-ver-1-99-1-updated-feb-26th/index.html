    Notice: Additional Improvements & Known Issues in Ver. 1.99.1, updated Feb. 26th

    February 26, 2026
    Mirror DungeonBalance

    Hello, this is Project Moon.

    We would like to inform you about the Bug Fixes & Improvements that were applied in ver. 1.99.1 but were missing from the Feb. 26th Scheduled Update Notice, and share any Known Issues identified after today's update.

    Please continue reading for more information.

    [ Additional Bug Fixes & Improvements After Ver. 1.99.1 Update ]

    ▶ Fixed an issue where "Identity Takeoff Ticket" could not be used to Uptie an Identity that has reached the pre-60 max level cap limited by story progress

    ▶ Fixed an issue where, after changing the Team loadout in a Mirror Dungeon run, the Skill Replacement UI would show the newly-loaded Identity's Skills corresponding to the Uptie Tiers of the Identity it replaced

    ▶ Fixed an issue where, under certain circumstances, Identities that fit the condition did not appear for Skill Replacements in Mirror Dungeon Shops after replacing their Skill 1 with Skill 2

    ▶ Fixed an issue where using the Skill Replacement function in Mirror Dungeon Shops did not update the number of Skills owned

    [ Known Issues After ver. 1.99.1 Update ]

    ▶ (AOS, iOS) An issue where, on mobile devices, viewing detailed information for Identities or E.G.O does not load their respective illustrations

    ▶ An issue where entering the Mirror Dungeon Team loadout menu causes the fade-to-black animation to play awkwardly

    ▶ An issue where post-Mirror Dungeon UI for obtained items causes Starlight to appear

    ▶ An issue where viewing the announcement in the Window UI does not remove the red notification marker

    ▶ An issue where the game could freeze when battling certain enemies while carrying the E.G.O Gift "Omni-tool"
    ※ This issue is occurring in Encounters against enemies that enter with hidden parts, such as Faelantern or Muddled Heishou of the Corpse Palanquin

    We sincerely apologize for the inconvenience.
