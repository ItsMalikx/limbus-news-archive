    (Steam) Notice: Version Update for Progression-blocking Issues in Ver. 1.106.0

    May 28, 2026
    Mirror DungeonRefraction Railway

    Hello, this is Project Moon.

    Ver. 1.106.1 that fixes the known issues identified in Ver. 1.106.0, updated May 28th, will be deployed soon.

    This update will be deployed to Steam first.

    As mobile platforms (AOS, iOS) require the update to go through each respective market review, the update cannot be deployed immediately in the case of mobile environment.

    Until the update is applied on the AOS and iOS platforms, we would like to ask our mobile users to access the game on Steam if possible.

    We will inform you via a separate notice as soon as updates become available on each AOS and iOS platform.

    Please refer below for more information.

    [Issues to be Fixed with the Ver. 1.106.1 Update]

    ▶ (Steam) Fixed an issue where resolution settings could not be freely changed in Windowed Mode

    ▶ Fixed an issue where, under certain conditions in Refraction Railway Line 6, the turn count would loop and pass indefinitely, blocking battle progression

    ▶ Fixed an issue where, in Refraction Railway Line 6, the game would stop responding during battle animations when The House of Spiders: The Index Nursefather Yi Sang uses Furioso-Replica against a certain enemy

    ▶ Fixed an issue where, after the update, the game would stutter at various points
    - Moving between nodes in the Mirror Dungeon
    - Making choices and running Skill checks in Mirror Dungeon Choice Events
    - Making purchases in Mirror Dungeon shops
    - Selecting Combat Encounters and viewing the pre-battle enemy info UI (Refraction Railway, Story Combat Encounters, Mirror Dungeon Combat Encounters, etc.)

    [Version Update Schedule]

    - 5.28 (Thu), after 23:00 (KST)
    - There may be a delay of approximately 10 minutes.

    ※ Once the update has been applied normally, the version number displayed at the bottom right of the title screen will show 1.106.1.

    Additionally, regarding the issue on AOS where "a black screen appears upon launching Limbus Company, blocking game launch", we are currently working to resolve the problem as quickly as possible.

    We sincerely apologize for the inconvenience.
