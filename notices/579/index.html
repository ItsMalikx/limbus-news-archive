New Feature
-----------

1. Luxcavation Consecutive Battle Update
A new Consecutive Battle feature has been added to the Luxcavation Dungeon, allowing repeated runs or skips.

- The Consecutive Battle UI will appear at the top of each Luxcavation UI upon clearing them for the first time.
- You may set up to 10 Consecutive Battles.
- Enkephalin Modules will be consumed according to the number of runs completed.
※ Consecutive Battles are only available for Luxcavation Dungeons cleared at least once.
※ Daily bonus rewards for Thread Luxcavation can only be obtained up to 3 times per day, even when using the Consecutive Battle feature.
※ When losing or forfeiting the battle during Consecutive Battles, Enkephalin Modules used and Rewards yielded will be based on the current number of runs completed.
※ Additional details can be checked via the Settings button during Consecutive Battle.

Bug Fixes & Improvements
------------------------

► Changed the timing of Enkephalin Module consumption in Luxcavations
- Before : Daily Bonus & Modules were consumed upon entering Luxcavations
- After : Daily Bonus & Modules are now consumed upon exiting Luxcavations

► Adjusted the in-game calculation logic so that Skills with "use Coin X an additional time" used by certain Identities or enemies are reflected in the Win Rate & Damage forecasts
- Identities whose Win Rate & Damage forecasts are affected : Shi South Section 5 Ishmael (Skill 2), The Ring Fauvist Student Meursault (Skill 3)
- Identities whose Damage forecast is affected : Kurokumo Clan Wakashu Hong Lu (Skill 2)
※ Win Rate forecasts will now take additional Skill Coin uses into their calculation.

► Fixed an issue where, in the Mirror Dungeon, owning the E.G.O Gift "Universal Instinct" without any The Ring-faction Identities in your Team could cause the battle to be unresponsive

► Fixed an issue where certain Passive and Skill effects on an enemy unit in Chapter 9.5 - 'Twining Threads' do not work as intended
(1) Passive : The Ring's Docent of Fauvism
※ Relevant effect : Immediately Before Getting Hit by a Skill that has 1 Atk Weight, if there is an allied Student of the Ring, have the said unit take the attack instead
- Before : The above effect activated even for Unclashable Skills, Clashable Guards, Guards, and Evade Skills
- After : Adjusted the behavior to match the description. Fixed an issue where the Sinners' Evade Skills could not evade the boss's attacks second Coin onward

(2) Skill : Finishing Touch, 3rd Coin effect
- Before : "[On Hit] Inflict 2 Sinking" inflicted 3 Sinking
- After : The ability now inflicts 2 Sinking, as described

► Fixed an issue where Clash Win Rate calculation would not be affected when a boss unit from Chapter 9.5 - 'Twining Threads' used a certain Skill
※ Relevant Skill effect : If the main target has Palette Vibrante, Clash Power +6

► Fixed an issue where, in the Mirror Dungeon Theme Pack - 'Twining Threads', if the boss unit's phase change occurs due to an E.G.O Gift that deals damage at Turn End, the phase change animation plays again the next turn

[ Cause ]
- When the enemy's HP hits the point where the phase change occurs, the phase change effect triggers at Turn End
- The E.G.O Gifts' Turn End effects activate after the Skill effects expire, which means that they trigger the phase change again in the next turn

[ Issue Fix ]
- Adjusted the effects so that the phase change trigger could be properly relayed even after E.G.O Gifts' "deal damage at Turn End" effect triggers

► Fixed an issue where the Abnormality "You Want To Get Beat? Hurtily?" can be killed even when its Surgery Stack is not at 5

[ Cause ]
- There is an invisible code within the "Surgery" status effect so that, when the "Surgery" status adjusts the unit's max HP, current HP is automatically adjusted proportional to the Max HP changes (rounding off to the nearest whole number).
- Mirror Dungeon has an effect that reduces the units' max HP by Floor.
- When "Surgery" Stack goes from 3 to 4, it interacts with the "reduce max HP" effect of the Mirror Dungeon, reducing the unit's max HP by more than 50%
- In this process, if the current HP before max HP adjustment was 1, rounding off to the whole number reduces the unit's HP to 0, killing the unit

[ Issue Fix ]
- Added a minimum HP cap so that when the unit's Current HP is adjusted due to the "Surgery" effect, the minimum HP is fixed at 1

► Fixed an issue where, when a boss unit appearing in Chapter 9.5 - 'Twining Threads' and Theme Pack - 'Twining Threads' uses a certain Skill, certain typography UI do not load properly

► Fixed certain awkward phrasing display in the Abnormality Choice Event for "kqe-1j-23"
