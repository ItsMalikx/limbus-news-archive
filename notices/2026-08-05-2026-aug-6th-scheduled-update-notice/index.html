Bug Fixes & Improvements

▶ Fixed an issue where the Skill 1 effect "Sword of the Homeland - Rending" of "Blade Lineage Mentor Meursault" would not appear in the Skill Keyword description section on the Combat screen

※ The effect itself was functioning normally; this fix only addresses the issue where it was not displayed in the Skill Keyword description section.

▶ (KR Only) Fixed an issue where Keyword tags were not applied to the Combat Passive and Support Passive text of "Molar Office Fixer Yi Sang"
- Before: 방어 레벨 1 감소 부여
- After: 방어 레벨 감소 1 부여

※ The effect itself was functioning normally. The text will be corrected to "Defense Level Down" to match the actual Keyword, and the appropriate Keyword tag will be applied.

▶ Fixed an issue where a certain effect of the "Near-light Superbattery" Keyword from the E.G.O Gift "Charge-type Gloves" would function differently than intended
→ Relevant Effect: Enemies gain +0.1 Resistance against this unit's attacks for every 20 Stack (max +0.5 Resist; does not activate against Staggered enemies)
- Before: When an Identity that has the "Near-light Superbattery" Keyword used a Skill, the effect would begin applying only after the first hit against an enemy
- After: The effect will now apply starting with the first hit against an enemy, as described

▶ Fixed an issue where a certain combat line from "Dawn Office Rep Gregor" would play differently than intended

▶ Fixed an issue where an unintended motion would play during a specific part of the animation when using Skill 3 while projecting "Lobotomy E.G.O::The Sword Sharpened with Tears Rodion" as a Façade

▶ Fixed an issue where certain tracks in the "Jukebox" would play differently than intended
→ Relevant BGM Tracks: "In Hell We Live, Lament", Canto II Battle 07, Canto VII Battle 14

※ Please note that a long-version track for "In Hell We Live, Lament" will be added to the Jukebox.

▶ Fixed an issue where the fade-out effect for a certain unit would be displayed differently than intended during a cutscene in Main Story 6-48

▶ Fixed an issue where the blink animations of certain E.G.O Gifts would not stop when viewing the "E.G.O Gifts Owned - Conditional" tab on the Mirror Dungeon Combat screen
