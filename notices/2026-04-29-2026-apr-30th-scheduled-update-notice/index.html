Substitution SP Bonus Error Notice

We have identified an issue where, when a Minus Coin Identity is substituted in Chain Battles, their entry SP bonus is modified with positive SP instead of with negative SP.

Please continue reading for more information.

[ Issue Details ]

- When a Minus Coin Identity is Substituted in, their entry SP bonus is adjusted with a positive modifier instead of negative

[ Issue Cause ]

- This issue occurred when deploying the following "Major Change" with the Apr. 17th, 2025 Scheduled Update
※ Major Change : Chain Battle is adjusted so that Substituted allies will now enter with bonus SP based on their Deployment order
- When implementing this system, the review process neglected to check for Minus Coin Identity modifiers, resulting in the implementation of incorrect values.

[ Issue Fix ]

- Allied Identities' SP modifiers in Chain Battles will now accurately reflect the values as stated in the Team loadout menu

※ This issue will be resolved with the Apr. 30th Scheduled Update.

We sincerely apologize for the inconvenience.

▶ Fixed an issue where, when applying Unique Tremor to the boss unit in "Reflectrial][lairtcelfeR - Twining Threads", Tremor Potency and Count would be treated as 0

- When calculating increases and decreases to a Keyword's Potency and Count caps, all Keywords were checked as the basis

- When Unique Tremor was applied, increases and decreases to both "Tremor" and "Unique Tremor" Keywords were calculated under the existing mechanism
- As the Passive implementation was applied twice, Unique Tremor was applied as "Potency -138, Count -178"

[ Issue Fix ]

- Changed the boss unit's Passive effect so that it applies to each Keyword individually rather than to all Keywords
