Notice: District 20 Yurodivy Hong Lu Skill 2 Error Fix

June 13, 2024

Hello, this is Project Moon.

We have identified an issue where the actual effect of District 20 Yurodivy Hong Lu Skill 2's "gain Coin Power" effect did not match the written text descriptions.
This will be fixed via a hotfix after 19:30 KST.
The hotfix will be downloaded when you re-open the game without a separate client update.
However, please note that additional downloads will occur.

Please refer below for more information.
We sincerely apologize for the inconvenience.

District 20 Yurodivy Hong Lu Error Fix Details

- Before
▶ Skill 2(enhanced in Uptie Tier 2 & 4)'s "At 6/5+ Tremor Count, gain Coin Power +1" effect activated at 10/8+ Tremor Count instead.

- After
▶ We have adjusted the actual conditionals to match the skill effect description as written.
- Uptie Tier 2: At 6+ Tremor Count, gain Coin Power +1
- Uptie Tier 4: At 5+ Tremor Count, gain Coin Power +1

Can be claimed once per account
