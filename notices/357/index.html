2025, Mar. 6th Scheduled Update Notice

March 3, 2025
Mirror DungeonNew ContentBalanceRewards

Greetings, Dear Manager.

The server will enter scheduled maintenance from 10:00 [AM] through 12:00 [PM] on Mar. 6th, 2025 (KST).

Please make note of the maintenance schedule; we recommend that you refrain from entering combat or making in-app purchases and close the application before maintenance begins so that no data is lost.

Please refer below for details about the update.

New Content

1. New Target Extraction [Firefist Office Survivor Gregor & Cinq East Section 3 Don Quixote] (25/03/06 12:00 ~ 03/20 10:00 (KST))

The following Identity will have increased odds of extraction.

- 3★ : Firefist Office Survivor Gregor, Cinq East Section 3 Don Quixote

※ Firefist Office Survivor Gregor is a Season 5 Identity.
※ Cinq East Section 3 Don Quixote is a Standard Fare Identity.

2. Target Extraction [Faust] (25/03/06 12:00 ~ 03/20 10:00 (KST))

The following Identities and E.G.O will have increased odds of extraction.

- E.G.O [WAW] : Everlasting Faust
- E.G.O [HE] : Thoracalgia Faust, Telepole Faust
- E.G.O [TETH] : Hex Nail Faust
- 3★ : LCE E.G.O::Ardor Blossom Moth Faust, MultiCrack Office Rep Faust, Blade Lineage Salsu Faust, Seven South Section 4 Faust, The One Who Grips Faust
- 2★ : Wuthering Heights Butler Faust, Zwei South Section 4 Faust, Lobotomy Corp. Remnant Faust, W Corp. L2 Cleanup Agent Faust
- 1★ : LCB Sinner Faust

3. Mirror of the Dreaming Rest Bonus Retention system added

Now, new Identities & Event Identities will retain max Rest Bonus for a certain relevant duration.

4. Mirror of the Dreaming Achievements - Part 2

Loadout and Shop categories will be added to the list of Achievements; Achievement Reward Levels will be expanded to Level 40.

5. New Packages

1 new limited package will be added to the game with the 2025. 3. 6 (KST) Scheduled Update.

▶ Identity Growth Pack
- Contents: Takeoff Module - ID Uptie x 1, Identity Training Ticket IV x 50, Identity Training Ticket III x 20
- Price: ₩33,000 / $21.99 / ¥3,000
- Purchase: Can be purchased twice
- Purchasable Period: 25. 3. 6 12:00 ~ 3. 20 10:00 (KST)

Major Changes

1. View Observation Level & Observation Log function added

Now, you can view each enemy's Observation Level and unlocked Observation Log from the enemy info window that appears before entering a Stage.

Bug Fixes & Improvements

▶ Fixed an issue where, at Turn Start after an ally Retreats, the fastest ally can't easily be selected

▶ (EN Only) Fixed a translation error in Sinclair E.G.O - Cavernous Wailing Threadspinning Tier 1, 2 Corrosion Skill
- Before : [Before Attack] At 3+ highest Reson., Atk Weight +1
- After : [Before Attack] At 4+ highest Reson., Atk Weight +1

▶ (EN Only) Fixed an issue where a certain Keyword in The Pequod Captain Ishamel's Skill 2 lacked a highlight

▶ (EN Only) Fixed a translation error in Yi Sang E.G.O - Dimension Shredder Threadspinning Tier 3, 4 Corrosion Skill
- Before : [Before Attack] Spend Charge to deal more damage (Max 75%)
- After : [Before Attack] Spend Charge Count to deal more damage (Max 75%)

▶ Fixed an issue where an incorrect E.G.O name was written in the Meursault E.G.O 'Screwloose Wallop' Passive description
- Before : You Want To Get Beat? Hurtily?
- After : Screwloose Wallop

▶ Fixed an issue where, in a shop, if the player purchases the same E.G.O they just obtained via Fusion, the notification UI appears incorrectly
※ The player would receive a vestige in this case, but we fixed this issue as it could cause confusion.

▶ Fixed an issue where, if the player enters the Mirror Dungeon and quits the expedition immediately without partaking in a Battle, only one Sinner would consistently appear in the failure menu

▶ Added a warning notification that triggers if the player tries to use an Identity Takeoff Ticket without having unlocked the requisite level cap

▶ Addressed an issue where Identity Uptie & E.G.O Threadspinning changes highlight functionality did not work properly

▶ Fixed an issue where the activation text for 'Torn Hems' E.G.O Gift would load even when it did not activate

▶ Clarified the E.G.O Gift 'Dueling Manual Book 3' E.G.O Gift description text

▶ Conducted RAM optimization for certain Encounters in Refraction Railway Line 5

▶ Fixed mistakes in certain Illustrations appearing in Stage 7-35

- If you're playing with a guest account, we recommend that you link your account with other platforms to prevent possible account loss.
- The maintenance compensation will be provided once per account. Please note that the distribution may be slow due to network delays or other causes.
