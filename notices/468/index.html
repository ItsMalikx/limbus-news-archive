Notice: Known Issues in Ver. 1.85.0 Updated Sep. 11th

September 11, 2025

Hello, this is Project Moon.

The following are the lists that have occurred on Ver. 1.86.0, updated Sep. 11th.
We will inform you via a notice when the following issues are fixed in our future updates.

Please continue reading for more information.

[ Known Issues ]

- An issue where N Corp. E.G.O::Contempt, Awe Ryōshū using "I Shall Fire / Anytime" doesn't activate the following effect: "[Combat Start] Atk Weight +1 for every 3 Torn Memory on self (max 2)

- An issue where N Corp. E.G.O::Contempt, Awe Ryōshū using "I Shall Fire/Anytime" doesn't activate the "[After Attack] If this unit has 7 Torn Memory at Combat Start, lose them all and heal 20 SP on self" effect if N Corp. E.G.O::Contempt, Awe Ryōshū lives after the attack

- An issue where using the base illustration(character art prior to Uptie 3) while using Skill 3 causes the illustration cut-in to look misaligned

- (EN Only) An issue where N Corp. E.G.O::Contempt, Awe Ryōshū's Skill "Awe, Contempt" labels its empowered Skill by an incorrect name

- An issue where using 'Takeoff Module - ID Uptie / Takeoff Module - E.G.O Spinning' could cause certain UI elements to malfunction

- An issue where certain nodes do not show the "Warning" tags in nodes such as Elite Battle nodes

- An issue where certain new E.G.O Gifts added Sep. 11th do not show their buff icons

- Incoming change to the "Hidden" Achievement category in Mirror:
Before : Obtain EX-Tier Gift Wealth/A Certain Philosophy
After : Unlock the EX-Tier E.G.O Gift "Wealth/A Certain Philosophy" in the E.G.O Gift Compendium

We apologize for the inconvenience.
