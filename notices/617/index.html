Notice: Known Issues After the Jun. 25th Scheduled Update

June 25, 2026

Hello, this is Project Moon.

After the Ver. 1.108.0 update on Jun. 25th, 2026, we have identified an issue where the game fails to respond when viewing the story in certain stages.

This issue has been confirmed to be caused by an error in the blood and dust particle effect applied to the characters' standing images via this update.

We will provide a separate notice once the issue is completely resolved and a hotfix schedule is confirmed.

Until the issue is resolved, please use the story Skip function as a workaround.

We sincerely apologize for the inconvenience.
