Bug Fixes & Improvements

► Added variations of the "Borrowed Time" buff name depending on its user
※ Because buffs used by these units shared the same name but not the effect, we decided to differentiate them to avoid confusion.
- Enemies in Canto IV: Borrowed Time of the Fathoms
- Enemies in Intervallo IV-1: T Corp. Borrowed Time

► Addressed the issue where there was a delay when skipping through Choice Event texts

► Fixed an issue where, in the list of Mirror Dungeon Starter Buffs - Active Effects, the description would sometimes go over the description box UI

► Fixed an issue where the Mirror Dungeon Floor Theme Pack [Sinking Deluge] boss image did not match the list of bosses appearing in that pack
※ We have adjusted the Theme Pack image to match the list of bosses actually appearing in that pack.

► Fixed an issue where, in the Mirror Dungeon Floor Theme Pack [The Unloving] boss Encounter, the auto-lose effect would activate immediately on the first wave

► Fixed an issue where certain summoned units' Sin resistance values were incorrectly inputted for the Wayward Passenger Encounter

► Fixed an issue where E.G.O Gift - Piece of Relationship did not activate in the Mirror Dungeon of the Fathoms

► Fixed an issue where certain enemies had incorrect names in Intervallo IV-1
- Before : T Corp. Class 2 Admin Staff
- After : T Corp. Class 2 Collection Staff

► (EN Only) Fixed a typo where, in the description for the Mirror Dungeon Starter Buff 'Katabatic Wind', the description said "Charnge" instead of "Charge"

► (EN Only) Fixed an issue where '스택' and '횟수' were both translated to 'Count' in the in-combat Buff viewing UI
- Before : 스택 was translated to "Count"
- After : 스택 is translated to "Stack"

Issues identified after the Jun. 27th, 2024 Scheduled Update

► An issue where certain damage types against enemies with the new debuff effect used by the upcoming T Corp. Identities makes it look as though the damage is applied instantly
※ This is a visual-only issue. The damage calculation works as written for that new debuff effect.

The above issue will be addressed with a future Scheduled Update, and we will inform you via a Scheduled Update Notice as soon as it is corrected.

We apologize for the inconvenience.
