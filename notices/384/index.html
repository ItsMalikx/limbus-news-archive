[Notice: Game Inaccessibility Issue Fix Deployed]

April 30, 2025

Hello, this is Project Moon.

The application review for the respective stores have been completed earlier than expected, so Ver. 1.75.1 update is available for download now.
Any users who have had an issue with playing the game should be able to access the game now.

[Game Inaccessibility Issue Fix Deployment]

- When: After 2025.04.30 22:00 (KST)
- Fixed Issue: An issue where certain devices(below Android OS Ver. 12) could not get past the additional in-game downloads window, making the game inaccessible

If you haven't encountered any issues with the previous version (Ver. 1.75.0),
there is no need to update your game to the new version (Ver. 1.75.1) to play the game normally.

If your respective store does not display the button to update the game,
please note that there may be a margin of error based on your device settings, and try again at a later time.

Once again, we sincerely apologize for the inconvenience.
