    Notice: Ver. 1.108.0 Known Issues and Hotfix ETA

    June 25, 2026
    Identities & E.G.OMirror DungeonRewards

    Hello, this is Project Moon.

    We would like to inform you of the known issues identified after the Scheduled Update on Jun. 25th, 2026, along with the hotfix schedule and detailed information.

    Please refer below for more information.

    [ To-be Hotfixed ]

    ▶ An issue where the game would become unresponsive when viewing certain story episodes
    - In our previous notice, we shared that we have identified an issue where the game fails to respond when viewing the story in certain stages.
    - This issue has been confirmed to be caused by an unexpected error that occurred in the process of enhancing the 'blood and dust particle effect applied to the characters' standing images,' which was deployed with this update. This issue will be fixed via the upcoming hotfix.

    ▶ An issue where The House of Spiders: The Thumb Apprentice Heathcliff is not treated as an "Identity that inflicts Burn and Tremor"
    - We have identified an issue where, if all of this Identity's Skills are replaced with its Skill 3 in the Mirror Dungeon, it would no longer count as an "Identity that inflicts Burn and Tremor".
    - Our investigation identified that the script written to determine whether the unique effects of this unit's Skill 3 count as inflicting "Burn" and "Tremor" did not trigger. The data regarding this issue will be corrected and applied to ensure it triggers correctly via this hotfix.

    [ Hotfix ETA ]

    - 06.25(Thu) 18:00(KST)
    - There may be a 10-minute delay.

    ※ The Hotfix will be deployed upon restarting the game, and does not require a separate client update. However, please note that additional in-game downloads may occur.

    [Issues To Be Fixed in the Next Scheduled Update]

    ▶ An issue where, in Mirror Dungeon, the game fails to respond under certain circumstances when possessing specific E.G.O Gifts

    <Issue Occurrence Conditions>

    1. Certain Mirror Dungeon E.G.O Gifts are in the player's possession
    2. "The House of Spiders: The Thumb Nursefather Rodion" is on the battlefield
    3. The error is triggered when "The House of Spiders: The Thumb Apprentice Heathcliff" Substitutes in

    ※ Relevant E.G.O Gifts
    Sanguine Fragrance Descends; Cleanup Agent Gear Set C; Bloody Flesh, Fleshy Blood; Hardblood Glaive; Lightning Axe; Flower in the Mirror; Moon in the Water; The End of all Evil; Desperado; Sorrowful Exhale; Raincloud; Uniform - Liu Assoc.; Carousel Figurine

    <Issue Cause>

    - This issue occurs because a function with restricted invocation was incorrectly called in certain initialization logics.
    - Since the internal logic must be modified and then submitted for review to each market, this issue cannot be immediately resolved through this hotfix.
    - Until this issue is fixed via the next Scheduled Update, please avoid the issue triggers listed above in-game.

    [6/25 Scheduled Update Error Compensation]

    - Content: Lunacy x500
    - Recipients: All users whose game accounts were created before Jul. 2nd, 2026, 10:00 AM (KST)
    - When: After Jun. 25th (Thu), 2026, 21:00 (KST)
    - Can be claimed once per account

    Relevant Compensation can be claimed until Jul. 2nd (Thu), 2026, 10:00 (KST) via the in-game Mailbox (mail available for 7 days).

    We sincerely apologize for the inconvenience.
