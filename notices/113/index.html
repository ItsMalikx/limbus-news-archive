August 31st Scheduled Update Notice

August 28, 2023

Greetings, Dear Manager.

The server will enter maintenance from 10:00 [AM] through 12:00 [PM] on August 31st, 2023 (KST) for system optimizations and content updates. Please make note of the maintenance schedule; we recommend that you refrain from entering combat or making in-app purchases and close the application before maintenance begins so that no data is lost. Please refer below for details about the update.

UI/UX Improvements

1. In-combat E.G.O Selection UI Changes

「E.G.O Selection UI」, which appears when pressing and holding the Sinner portraits, has been changed as follows. Also, now SP consumption for E.G.O Skills and Overclocked E.G.O Skills are both taken into account when calculating Corrosion rates (To Corrode)

UI/UX Improvements

2. Clash Arrow UI Improvements

The appearance of Clash Arrows will be changed as follows:

- Unopposed attack by an ally

- Unopposed attack by an enemy

- When Clashing

UI/UX Improvements

Clash Arrow toggle button functionality will be changed as follows:

- Clash Arrows toggled off

- Display one Clash Arrow at a time

- Display all Clash Arrows at once

Bug Fixes & Improvements

· Fixed an issue where ‘S.E.A. Event’ bonus Scrap UI appears in the Sinner loadout menu before entering the Mirror Dungeon
· Fixed an issue where the ‘Charge Barrier’ VFX does not appear when gaining Charge Barriers in the next turn
· Fixed an issue where Los Mariachis Jefe Sinclair’s Combat Passive does not function as intended
· Fixed the issue in Focused Encounters where player control of Skill Slots did not align properly with the visible UI

Issues Currently Being Fixed

· An issue where W Corp. L3 Cleanup Agent Ryōshū’s Uptie 4 「Charged Evade」 skill does not activate against the enemies’ second skill use

※ Because making direct changes to this skill could cause issues in other parts of the game, further investigation is required to correct this issue. We will notify you via a notice as soon as this issue is addressed. We apologize for causing inconvenience to your enjoyment of our game.
