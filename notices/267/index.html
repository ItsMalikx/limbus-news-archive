Notice: Steam Version 1.54.1 Deployed

August 8, 2024

[Notice: Steam Version 1.54.1 Deployed]

Hello,
This is Project Moon.

A new Client Version(1.54.1) with fixes for the issues that were identified in Version 1.54.0 has been deployed on STEAM as of Aug. 8th (THU) 19:00(KST).

Version 1.54.1 Changelog
- An issue where the game softlocks at Stage 5-18
- An issue where defeating every enemy at once under a specific condition in a Mirror Dungeon - Chain Battle causes the Encounter to end in a defeat, making it unable to proceed to the next Stage
- An issue where substituted Backup units do not gain additional Skill Slots in Regular Encounters Chain Battles
- An issue where VFX for the Passive of an enemy appearing in 6.5-2 lingers even after the Passive ends
- An issue where, in the Nominable Egoshard Crate opening UI, selecting and deselecting the Sinner's shards doesn't actually deselect the Sinner
- An issue where translations for the text in the popup window for 'Clear Selection' option in the Loadout Menu are not applied

If the game does not update to 1.54.1, please restart your STEAM client to proceed with the update.

We apologize for the inconvenience.
