[Notice: Mirror Dungeon Achievement Error Hotfix]

2025-03-19

Greetings, Dear Manager.

We have confirmed the following issue on version 1.72.0 of the game.

The hotfix will be applied upon restarting the game without a separate client update. However, please note that additional in-game downloads may occur.

Hotfix Deployment ETA
- 03.20(THU) 13:00(KST)
- There may be a ten minute margin of error to the above estimation.

Issue
- An issue where the reward for Mirror Dungeon Achievement [Clear all Missions] could not be claimed

Affected Users
- Users who cleared all Missions before the 03.20(THU) Scheduled Maintenance

Cause & Solution
- In the process of adding this new achievement, we made data adjustments based on the preexisting Achievement completion data, but did not include the completion flag
- This issue was fixed by making the completion flag adjust upon restarting the game.

We sincerely apologize for the inconvenience.
