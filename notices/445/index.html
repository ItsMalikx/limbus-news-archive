2025, Aug. 7th Scheduled Update Notice

2025-08-04

--------------------------------------

Greetings, Dear Manager.

The server will enter scheduled maintenance from 10:00 [AM] through 12:00 [PM] on Aug. 7th, 2025 (KST).

Please make note of the maintenance schedule; we recommend that you refrain from entering combat or making in-app purchases and close the application before maintenance begins so that no data is lost.

Please refer below for details about the update.

New Content
-----------

1. New Content [Mirror of Immortality Parallel Superposition Mode & Achievements]

※ Please refer to the Steam Announcements Page for more information.

※ For the Mirror of Immortality Parallel Superposition mode and Achievements implementation, Mirror Dungeon entry will be blocked for the following period: Aug. 7th, 2025 06:00 ~ 12:00 (KST)

Bug Fixes & Improvements
------------------------

► Fixed an issue where, in Stage 6.5-15 (Hard) Dungeon, a Choice Event option could not be interacted with despite having the requisite E.G.O Gift

► Fixed an issue where parts of E.G.O Gifts 'Lightning Axe, Flower in the Mirror, and Moon in the Water' did not work properly

※ Issue 1: Fixed an issue where the effects that are strengthened based on the number of Deployed Identities did not activate in the first Encounter after obtaining the E.G.O Gift

※ Issue 2: An issue where, in Chain Battles, Backup Unit Identities did not count toward the E.G.O Gift strengthening conditionals

► Fixed an issue where, if the enhanced version of E.G.O Gift 'Nebulizer' was equipped while Faust E.G.O 'Thoracalgia' Passive 'Breath' was activated, certain effects did not activate

※ Relevant Effects : First Turn Start of a wave: all allies gain X Poise Potency and +Y Poise Count

► Fixed an issue where parts of E.G.O Gifts 'Microprecision Time Accelerator' buff 'Microprecision Time Acceleration' did not work properly

※ Issue 1: Fixed an issue where the units' minimum and maximum Speed values did not apply immediately upon Encounter Start

※ Issue 2: Fixed an issue where Base Power, Damage, and Stagger Threshold-raising effects were boosted even for Skills that don't inflict Tremor Potency, Count, or trigger Tremor Burst

► (EN Only) Fixed an issue where the description for the Skill 'Mutilate' for the Boss enemy in Chapter 6.5 - Timekilling Time was incorrectly translated

- Before : [Clash Lose] At 75%-HP, consume 75 Stolen Time and gain Clash Power +2
- After : [On Use] At 75%-HP, consume 75 Stolen Time and gain Clash Power +2

► Removed the 'E.G.O Resource halved upon clearing a combat Encounter' effect from certain Dungeons of the Fathoms

※ Affected Dungeons : Ch. 3.5 - Hell's Chicken, Ch. 5.5 - Yield my Flesh to Claim their Bones, Ch. 6.5 - Timekilling Time

※ As they were built based on previous Mirror Dungeons, E.G.O Resources were getting halved with every encounter. That will no longer be the case with this Scheduled Update.

※ Please note that, in the Dungeon featured in Ch. 7.5 - LCB Regular Check-up, E.G.O Resources are already not getting halved between each Encounter.

► Changed the Floor from which 'Refraction Railway Line 1' Mirror Dungeon Theme Pack may appear

- Before : Hard Difficulty Floor 4
- After : Hard Difficulty Floor 4, Floor 5

► Fixed an issue where the 'Remove 3 E.G.O resources of a random Affinity' effect did not activate for an enemy Skill 'Mantra'

► Fixed an issue where, in Shops featured in Dungeons of the Fathoms, it appears as though the Identities are affected by previous level caps

※ This is a visual-only issue; the Identities' actual levels are reflected in those Dungeons.

► Adjusted the interaction needed to access the Team Loadout menu in Dungeons of the Fathoms

- Before : Select the list of Sinners at the bottom of the screen to view the Team Loadout menu.
- After : Select the View Loadout button (Person-shaped Icon) to view the Team Loadout menu.

► Fixed certain visual misalignments in Don Quixote E.G.O 'In the Name of Love and Hate' Illustration

► Fixed an issue where the halo effect that appears in battle against Abnormality 'My Form Empties' was missing

► Fixed an issue where certain visual effects for Heishou Pack - Si Branch Identities did not appear in certain circumstances

► Fixed a line break issue for the Abnormality 'Sign of Roses' effect 'Blooming Sin' buff tooltip

► Fixed an issue where the top line text could be cut off in the buff tooltip UI

► (JP Only) Fixed an issue where, when using Meursault E.G.O 'Crushbound Past', the subtitles extended beyond the screen boundaries

► (EN Only) Adjusted the translated text length for "Herbert" Announcer's voicelines to fit into the Announcer text box UI

► Added summaries to Combat & Support Passive activation description texts so that the passive texts won't clutter the combat phase

※ Affected Identities : Lobotomy E.G.O::In the Name of Love and Hate Don Quixote, Lobotomy E.G.O::The Sword Sharpened with Tears Rodion

► Fixed an issue where the Ch. 6.5 Timekilling Time boss enemy's voice triggers too often when getting hit

► (EN, JP Only) Fixed an issue where the description text that appears upon using the Team swap function in Mirror Dungeon Shops appeared untranslated

► (KR Only) Fixed various typos for the 'Herbert' Announcer

► (JP Only) Fixed an issue where Ruby text tags were exposed in certain sentences

Notes

- If you're playing with a guest account, we recommend that you link your account with other platforms to prevent possible account loss.
- The maintenance compensation will be provided once per account. Please note that the distribution may be slow due to network delays or other causes.
- The update gifts are valid to claim for 7 days. Please redeem them within this timeframe.

Thank you.
