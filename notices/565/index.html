Mar. 19, 2026 Hotfix, Missing Items, Known Issues

Hello, this is Project Moon.

In this notice, we would like to inform you about the following: 1) Hotfix for certain Known Issues, 2) update content that was deployed but omitted from this week's Scheduled Update Notice, and 3) Known Issues that have been identified so far.
