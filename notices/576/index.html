Notice: Additional Improvements & Hotfix After 26.04.16 Scheduled Update

April 15, 2026

Hello, this is Project Moon.

We would like to inform you of additional improvements that were not included in the update notice for Version 1.103.0 (deployed Apr, 16, 2026) and the schedule for a hotfix.

Please refer below for more information.

[ Additional Improvements After Update ]

▶ Updated the text for the Skill description of the Abnormality "Fairy-Long-Legs" to match its current behavior
※ Relevant Skill: Casting Shade
- Before : [On Use] Deal +5% damage per Bleed Count
- After : Removed the above text
※ To maintain the current combat experience, the text will be adjusted to reflect the current behavior.

[ Issues to be Fixed via Hotfix ]

▶ An issue where the new entries of Dante's Notes do not appear even after fully clearing Chapter 9.5 "Twining Threads"

: Cause of the Issue
- Prior to the deployment of Version 1.103.0, the unlock condition for new entries of Dante's Notes had been incorrectly set to clearing Episode 9 instead of Episode 9.5. In order to address this, we had temporarily restricted access to the new Dante's Notes.

: Issue Fix
- New entries of Dante's Notes will now appear properly after fully clearing Chapter 9.5 "Twining Threads".

[ Hotfix Schedule ]
- Apr. 16th (Thu) 13:30 (KST)
- Please note that there may be a delay of approximately 10 minutes.

※ The hotfix will be applied upon reconnecting to the game without requiring a version update. Please note that additional download data may occur.

We sincerely apologize for the inconvenience.
