[Notice: Refraction Railway Line 4 Error Fix Deployment]

Hello,
This is Project Moon.

The new Client(1.51.1) update with fixes for the issues identified in the 1.51.0 version updated July 4th (THU) 12:00 (KST) will be deployed.
This update will be deployed first on STEAM, and we will inform you via an additional notice after they pass the platform reviews.

Deployment ETA
- July 4th(THU), 23:00 (KST)

Version 1.51.1 Changelog
- Fixed an issue where, in Refraction Railway Line 4 Section 1 Wave 1, if an enemy spawned mid-Encounter is killed by the "Burn" effect, the game softlocks
- Fixed an issue where certain enemies in the Refraction Railway Line 4 plays special Identity voicelines
- Fixed an issue where winning the final battle of Canto V Story Dungeon causes the game to softlock
- Fixed an issue where Stage 6-44 enemy pattern does not work as intended

Version 1.51.0 & 1.51.1 Changelog (Universal between iOS, Android, and STEAM)
- An issue in Refraction Railway Line 4 where the E.G.O resource gain upon ally defeat doesn't work as written (this change does not require a client update; however, please note that additional in-game downloads will occur)

We sincerely apologize for the inconvenience.
