2024, Sep. 26th Scheduled Update Notice

September 23, 2024
EventsNew ContentBalanceMain Story

Greetings, Dear Manager.

The server will enter scheduled maintenance from 10:00 [AM] through 12:00 [PM] on Sep. 26th, 2024 (KST).
Please make note of the maintenance schedule; we recommend that you refrain from entering combat or making in-app purchases and close the application before maintenance begins so that no data is lost.
Please refer below for details about the update.

New Content

1. New Dante's Notes entries added
New entries to Dante's Notes will be added after the Sep. 26th (KST) Scheduled Update.
※ Unlock Conditions : Clear Main Story 6.5-30

2. New Users & Returning Users Event
※ Please refer to the Steam Announcements page for more information.

New Content

1. Added a new UI element to the Dashboard that shows up when Devyat' North Section 3 Rodion can activate the 'Strategic R&R Mode'.

2. Now Luxcavations will display bonus rewards for skipping Luxcavation encounters separately
- Before : Showed the sum of total rewards from both base and bonus rewards
- After : Shows base rewards and bonus rewards separately
※ e.g. If the player received 4 base rewards and 2 rewards for skipping a Luxcavation, it used to show 6 rewards; however, after the update, it will show 4 and 2 rewards separately.

3. Adjusted Identity Uptie & E.G.O Threadspinning upgrade UI with the addition of new items

Bug Fixes & Improvements

▶ Fixed an issue where Lobotomy E.G.O::Lantern Don Quixote's Skill 3 could be Reused multiple times in a row

▶ Fixed an issue where the game crashes when attempting to replace a Skill in a Mirror Dungeon Shop

▶ Fixed an issue where the E.G.O Gift 'Crossed Knot' was activating at an incorrect timing
- Before : Was checking for conditions and activating whenever Skill Use ended
- After : Checks for conditions and activates at Turn End, as written in the description

▶ Fixed an issue where the E.G.O Gift 'Pocket Watch : Type P' applied 'Offense Level Up' at an incorrect timing
- Before : Was applying from the fastest unit to the slowest unit
- After : Applies from the slowest to the fastest, as written in the effects description

▶ (EN, JP Only) Fixed an issue where a certain character was missing their names in Main Story 3-8

▶ Fixed an issue where inputting a shortcut key in the chaining phase could start the combat phase, even when long pressing to enter the E.G.O menu
※ We adjusted the settings so that shortcut keys won't activate when the mouse is moving.

▶ Fixed an issue where, under certain conditions, a certain Main Story boss would infinitely skip turns

▶ Fixed an issue where, after successfully using an Evade type defensive skill, and when 2+ allies defend themselves against an AOE attack, the game softlocks

▶ Adjusted Defense Skill activation timings for certain enemies
※ Relevant Skills
(1) Abnormality - Ardor Blossom Moth's 'Evade'
(2) Main Story 6.5-2 (Murder on the WARP Train) boss' 'Leave Me Alone....!'

※ Changes
- Before : [On Use]
- After : [On Evade Use]

Known Issues after the 24/09/26 (KST) Update

▶ An issue where, if the player 1) enters The 4th Walpurgis Night 'Noon of Violet' Hard difficulty TEAM Loadout menu, 2) opens a Sinner's detailed info and enters their Identity Uptie or Threadspinning menu, and 3) enters the inventory or the Shard::Thread Exchange menu, the screen UI loads incorrectly and cause progression issues
※ Restarting the game will resolve this issue.

▶ An issue where certain resources do not load for The 4th Walpurgis Night 'Noon of Violet' Encounter

Maintenance & Application Update Compensation

- Content: Lunacy x300
- Recipients: All users whose game accounts were created before 10:00 Oct. 3rd, 2024 (KST)
- When: After Sep. 26th, 2024 (Thu) 12:00 (KST)
- Can be claimed once per account

Maintenance Compensation can be claimed until Oct. 3rd (Thu) 2024, 10:00 (KST) via the in-game Mailbox. (Mail available for 7 days)

Notes

- Please update your game client to the newest version on the respective store (Google Play/App Store/Steam).
- Forcibly shutting down the game while it is downloading resources may cause the download to fail, so please be careful not to close the application during the download.
- You will not be able to play <Limbus Company> during maintenance. Please understand.
- The maintenance schedule may suddenly change depending on the status of maintenance. If such a change occurs, we will let you know in a follow-up notice.
- A resource download may be prompted after the build update. If you're using a mobile device, it is recommended to proceed with a Wi-Fi connection.
- If you're playing with a guest account, we recommend that you link your account with other platforms to prevent possible account loss.
- The maintenance compensation will be provided once per account. Please note that the distribution may be slow due to network delays or other causes.
- The update gifts are valid to claim for 7 days. Please redeem them within this timeframe.

Thank you.
