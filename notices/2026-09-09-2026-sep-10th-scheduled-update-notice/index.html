2026, Sep. 10th Scheduled Update Notice

September 9, 2026
New ContentBalanceRewards

Greetings, Dear Manager.

The server will enter scheduled maintenance from 10:00 [AM] through 12:00 [PM] on Sep. 10th, 2026 (KST).

Please make note of the maintenance schedule; we recommend that you refrain from entering combat or making in-app purchases and close the application before maintenance begins so that no data is lost.

Please refer below for details about the update.

Major Changes

1. The end date for Season 7 Battle Pass will now be visible.

Bug Fixes & Improvements

▶ Fixed an issue where Poise Count would be consumed when flipping Coins for Skills that have the "Does not hit" effect
→ Relevant Identities : The House of Spiders: The Ring Nursefather Hong Lu's "My, How We Love the Flesh and the Blood" Skill
→ Relevant E.G.O : Tears of the Tarnished Blood [污血泣淚] Hong Lu's "Tears of the Tarnished Blood - Inception [始]" Skill, Unbrilliant Glory Gregor's "Unbrilliant Glory - Flowing"

※ This issue will be fixed for enemies and Assist Units that have the "Does not hit" effect as well.

▶ Fixed an issue where the targeting for Skills that are "on random characters/units" or "all characters/units" would not work as intended
- Before: When activating relevant Skills, the "self," or the unit who activated the Skill, was excluded from the list of affected units
- After: When activating relevant Skills, the "self," or the unit who activated the Skill, will be included in the list of affected units as well
→ Relevant Skills
(1) "Telepole Faust" E.G.O Corrosion Skill
- Threadspinning Tier 3: [Tails Hit] Inflict 2 Paralyze and 2 Bind on 2 random units next turn
- Threadspinning Tier 4: [Tails Attack End] Inflict 2 Paralyze and 2 Bind on 2 random units next turn, gain +3 Charge Count
(2) "Capote Meursault" E.G.O Corrosion Skill
- Threadspinning Tier 1&2 : [On Hit] ... if the Tremor Burst Staggered the target, inflict +2 Burn Count on 5 random units
- Threadspinning Tier 3: [On Hit] Inflict 2 Burn on 5 random units; [On Hit] ... if the Tremor Burst Staggered the target, inflict +3 Burn Count on 5 random units
- Threadspinning Tier 4: [On Hit] Inflict 3 Burn on 5 random units; [On Hit] ... if the Tremor Burst Staggered the target, inflict +4 Burn Count on 5 random units
(3) "Capote Ishmael" E.G.O Corrosion Skill
- [On Hit] ... if the Tremor Burst Staggered the target, inflict +2 Burn Count on 3 random units
(4) "My Form Empties" Abnormality Passive "Cyclical Karma"
- All units transfer 10 of their Karma to their targets On Hit

※ We have confirmed that these effects were all working normally up until after the March 7th, 2024 Scheduled Update. This fix resolves this issue, reverting them to working as intended again. We sincerely apologize for the delayed discovery of this issue, which led to a late fix deployment.

▶ Fixed an issue with "Heishou Pack - Mao Branch Outis", in which the Identity's Skill 3 Coin 4's final hit damage typography would show 0 damage

※ The coin in question is a coin that has 2 hit effect timings. However, this issue caused the first of two hits to display the Skill's full damage output all at once, making the second and final hit display 0 damage.

※ The damage output is working as intended; this is a typography fix that affects only the damage distribution display within a single Coin so that the final hit does not display 0 damage.

▶ (JP Only) Fixed a typo in "9:2 Faust" E.G.O Threadspinning Tier 5
- Before : [攻撃前] 円攻撃対象と自分の火傷威力の合計1につき、ダメージ量+5%(最大100%)
- After : [攻撃前] 全攻撃対象と自分の火傷威力の合計1につき、ダメージ量+5%(最大100%)

※ Its effects are working as written in the fixed description. This fix only addresses the typo in the Japanese text.

▶ (JP Only) Fixed an issue where certain text elements do not load properly in the "Set Loading Art" menu

▶ Fixed an issue where viewing detailed info for an E.G.O that has Threadspinning Tier 5 would cause UI elements in subsequent viewings of other Identities or E.G.O to malfunction

▶ Fixed an issue where filter descriptions for "Set Loading Art" menu would not be contained within the UI boundaries

▶ Added certain missing artwork to the "Set Loading Art" menu and adjusted the location of files in incorrect categories
