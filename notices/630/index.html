Notice: Aug. 20th Scheduled Update Addendum & Known Issues in Ver. 1.112.0

August 20, 2026

Hello, this is Project Moon.

A missing bug fix entry has been identified in the Aug. 17th Scheduled Update Notice, uploaded this Monday.

We would like to share that entry, along with the known issues identified in Ver. 1.112.0. Please continue reading for more information.

< Missing Bug Fix entry from the Aug. 20th Scheduled Update >

▶ (EN Only) Fixed an issue where an enemy unit in Main Story Stage 8-30 had an incorrect Passive description
- Before: "Encounter Start": If this unit has 3+ Bind, the above effect does not activate; gain Defense Level Down equal to Bind on self (max 9)
- After: "Combat Start": If this unit has 3+ Bind, the above effect does not activate; gain Defense Level Down equal to Bind on self (max 9)
※ This fix only addresses the incorrect translation in the English version of the game; the effect in question was working as described in the amended description.
※ The enemy unit in the Mirror Dungeon Theme Pack "Chachihu" had the same incorrect translation; this fix addresses that issue as well.

< Known Issues after Aug. 20th Scheduled Update >

▶ An issue where, in "Reflectrial][lairtcelfeR - Chachihu", the starting SP bonuses do not work as intended for certain Identities when deployed as fielded units
→ Affected Identities: LCE E.G.O::Lantern Yi Sang, Blade Lineage Mentor Meursault
※ This issue will be addressed with next week's Scheduled Update.

We sincerely apologize for the confusion caused by the omission of the bug fix entry in this week's Scheduled Update.
