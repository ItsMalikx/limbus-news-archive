    Notice: Ver. 1.107.0 Known Issues and Hotfix ETA

    June 11, 2026
    Main Story

    Hello, this is Project Moon.

    We would like to inform you about the known issues identified after the Jun. 11th, 2026 Scheduled Update, and the ETA for a Hotfix that addresses some of them.

    Please continue reading for more information.

    < To-be Hotfixed >

    ▶ Fixed certain awkward phrases in Ch. 9.5 "Mnestic Experience" story

    ▶ Fixed an issue where, in Ch. 9.5 "Mnestic Experience" story, certain Standing illustrations would load incorrectly

    ▶ Fixed an issue where, in Ch. 9.5 "Mnestic Experience" story, certain parts of a boss unit's flavor text did not match the intent

    ▶ Fixed an issue where the "Mnestic Experience" Mirror Dungeon theme pack image would not load

    ▶ Fixed an issue where incorrect BGM would load when playing through the "Mnestic Experience" Mirror Dungeon theme pack

    ▶ Fixed an issue where the icon for a Keyword used by "Night Awls Capitano Gregor", "Open Wound" would not load

    ▶ Fixed an issue where, when hovering over "The House of Spiders: The Middle Nursefather Outis" with a mouse cursor, the sword's sprite on the unit would not correspond with the actual unsealing stage

    < Hotfix ETA >

    - Jun. 11th (Thu) 19:30 (KST)
    - There may be a 10-minute delay.

    ※ The Hotfix will be deployed upon restarting the game, and does not require a separate client update. However, please note that additional in-game downloads may occur.

    < Issues to be resolved with the next Scheduled Update >

    ▶ An issue where using the Continue function in the main story Dungeons of the Fathoms would not fully heal the Identities

    ▶ An issue where certain VFX are missing from the "To Claim Their Bones" Skill used by "Blade Lineage Meursault" after activating the "Shadow-vested Bladesinger" E.G.O

    ▶ An issue where, in one of the tutorial battle Encounters, the description regarding Passives is incorrectly highlighted

    < Issues currently under investigation >

    ▶ An issue where, on mobile platforms, entering loading screens or battles would cause the game to crash

    ※ This issue has been identified to have occurred after the May 28th Unity version upgrade, and we have confirmed that the game's stability has been improved after today's Scheduled Update.

    However, we have received reports that the issue persists on certain devices, and we are working closely with Unity's technical support team to address it.

    We will continue to monitor and investigate to resolve this issue.

    We sincerely apologize for the inconvenience.
