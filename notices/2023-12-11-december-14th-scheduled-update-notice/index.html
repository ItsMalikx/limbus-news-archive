December 14th Scheduled Update Notice

December 11, 2023
Identities & E.G.OMirror DungeonNew ContentBalance

Greetings, Dear Manager.

The server will enter scheduled maintenance from 10:00 [AM] through 12:00 [PM] on December 14th, 2023 (KST). Please make note of the maintenance schedule; we recommend that you refrain from entering combat or making in-app purchases and close the application before maintenance begins so that no data is lost. Please refer below for details about the update.

Known Issues

▶ An issue where the Uptie 4 effects of Tingtang Gang Gangleader Hong Lu's Skill 3 'Mutilate', "[Reuse - Heads Hit] If target has 10+ Bleed, deal +50% damage" activated on [On Hit] instead
※ We have identified that a certain effect in Tingtang Gang Gangleader Hong Lu's Skill 3 'Mutilate' activated on incorrect conditions. If this error were to remain unfixed, the +50% damage would activate regardless of whether Tingtang Gang Gangleader Hong Lu's special trait activated - which is reusing coins. This means that this skill was not working as intended, so we would like to fix this issue. We sincerely apologize to any users who have been using Tingtang Gang Gangleader Hong Lu.

▶ (iOS, Android) An issue where, after a specific sequence of UI movements, Main Story UI and Luxcavation UI would overlap each other
