2025, Nov. 6th Scheduled Update Notice

November 3, 2025
EventsIdentities & E.G.ONew ContentBalance

Greetings, Dear Manager.

The server will enter scheduled maintenance from 10:00 [AM] through 12:00 [PM] on Nov. 6th, 2025 (KST).

Please make note of the maintenance schedule; we recommend that you refrain from entering combat or making in-app purchases and close the application before maintenance begins so that no data is lost.

Please refer below for details about the update.

New Content

1. New Target Extraction [The 7th Walpurgis Night]
(2025/11/6 12:00 ~ 11/20 10:00 (KST))
The following Identities will have increased odds of extraction.
- 3★ : Jeong's Office Rep. Ishmael, Night Awls Capitano Gregor
- Announcer: Gebura Announcer

※ Jeong's Office Rep. Ishmael and Night Awls Capitano Gregor are WALPURGISNACHT-VII Identities.

2. Target Extraction [The 2nd & 3rd Walpurgis Night.]
(2025/11/6 12:00 ~ 11/20 10:00 (KST))
The following Identities, E.G.O, and Announcers will have increased odds of extraction.
- E.G.O [WAW] : Sanguine Desire Rodion
- E.G.O [HE] : Wingbeat Ishmael
- 3★ : Lobotomy E.G.O::Magic Bullet Outis, Dawn Office Fixer Sinclair
- 2★ : Lobotomy E.G.O::Lantern Don Quixote
- Announcers: Malkuth Announcer, Jack/Pierre Announcer, Yesod Announcer, Molar Office Announcer
※ Please note that [The 7th Walpurgis Night Target Extraction] and [The 2nd & 3rd Walpurgis Night Target Extraction BokGak] are separate Extractions, and feature different improved rates. Please confirm each Banner’s featured units and Probabilities menu prior to extracting.

3. Walpurgis Night Identities & E.G.O Added
During the event period, all Walpurgis Night Identities & E.G.O will be added back to the list of extractable Identities & E.G.O.
※ The event period lasts from Nov. 6th, 12:00PM to Nov. 20th, 10:00AM (KST).

※ Please note that Walpurgis Night Identities & E.G.O will be withdrawn from the list of extractable Identities & E.G.O once the event period is over.

4. New Content [Enkephalin Spending Event - A Certain Library's General Invitation]
※ Please check the Steam Announcements page for more information.

Bug Fixes & Improvements

▶ Fixed an issue where Skills that gain Coin Power at [Coin Start] reflect those values for Clash forecasts as well
※ Affected Identities: T Corp. Class 3 VDCU Staff Outis, W Corp. L4 Cleanup Agent - CCA Heathcliff
※ This effect increases Coin Power at the actual start of an Attack. Following this fix, the value will no longer be reflected for Clash forecasts.

▶ Fixed an issue where T Corp. Class 3 VDCU Staff Outis's 'Borrowed Time' sprite motion would duplicate under certain conditions.

▶ Fixed an issue where Assist Attacks would not trigger if the ally designated for an Unopposed Assist Attack had zero Skill 1s remaining after all Skill 1s were replaced.

▶ Fixed an issue where certain E.G.O Gifts would incorrectly activate and consume a trigger count when an ally with a Shield took damage that only depleted the Shield, without meeting the trigger condition 'when taking damage that reduces this unit’s HP to N.'
※ Affected E.G.O Gift: Swishing Fuel Tank, Unhatched Embers, Jin Gang Bolus

▶ Fixed an issue where certain effects of E.G.O Gift 'Bloody Flesh, Fleshy Blood' did not apply on Shields
※ Affected Effect: Allies take -(N x 10%) Bleed damage (min 1 Bleed damage; max 40%)

▶ (KR Only) Fixed an issue where duplicate words displayed under The Manager of La Manchaland Don Quixote's battle keyword 'Hardblood III' tooltip
- Before: 턴 시작 시 수치 5 당 공격 레벨 증가 1, 방어 레벨 증가 1 얻음 얻음
- After: 턴 시작 시 수치 5 당 공격 레벨 증가 1, 방어 레벨 증가 1 얻음

▶ Fixed an issue where, in Hong Lu E.G.O - To Remain Oneself [宁作吾]'s Corrosion animation, the sword object would load incorrectly

▶ Fixed an issue where, in a certain Choice Event featured in Stage 4-54's Story Dungeon 1st Floor, if the Choice Event result applied to allied units, the incorrect unit received the effect

▶ Fixed an issue where "Victory Cry" and "Defeat Wail" Announcer voicelines did not trigger

▶ Adjusted the story text loading animation: for center-aligned texts, the text animation would now play starting from the left side instead of loading in from the middle

▶ Fixed an issue where, in the resource download menu, the download speed indicator would show an abnormal value

▶ Fixed an issue where, if the player deletes their account and creates a new account, the deleted account's event mission progress data remained

▶ Fixed an issue where, if the player was made to enter the Window UI before the resource download process was completed, certain texts in the game would not load properly

▶ (JP Only) Fixed an issue where descriptions for W Corp. L4 Cleanup Agent - CCA Heathcliff's Skill 3 Coin effects and Skill effects appeared overlaid on each other

▶ (JP Only) Fixed an issue where the tooltip for W Corp. L4 Cleanup Agent - CCA Heathcliff's Keyword, "Overcharge" was not fully visible

▶ (JP Only) Fixed a translation issue on Liu South Section 6 Gregor's Support Passive
- Before : 速度が最も低い味方1名の、 3番目以降のコインからダメージ量 +30%
- After : 速度が最も低い味方1名の、 ”3枚目より後ろ”のコインからダメージ量 +30%

▶ (EN Only) Fixed an issue where the "Collaboration - Limited" filter visible when switching to different Illustrations from the Window tab or Ticket Deco in the manager profile menu did not fit properly into the UI

▶ (EN, JP Only) Fixed an issue where Keyword description for the Mirror Dungeon Rental team loaded as "UNKNOWN"
※ This issue occurred on the Rental Team introduced with the Oct. 30th, 2025 Scheduled Update.

Maintenance & Application Update Compensation

- Recipients : All users whose game accounts were created before 10:00 Nov. 13th, 2025 (KST)
- When : After Nov. 6th, 2025 (Thu) 12:00 (KST)

Notes

- Please update your game client to the newest version on the respective store (Google Play/App Store/Steam).
- Forcibly shutting down the game while it is downloading resources may cause the download to fail, so please be careful not to close the application during the download.
- You will not be able to play <Limbus Company> during maintenance. Please understand.
- The maintenance schedule may suddenly change depending on the status of maintenance. If such a change occurs, we will let you know in a follow-up notice.
- A resource download may be prompted after the build update. If you're using a mobile device, it is recommended to proceed with a Wi-Fi connection.
- If you're playing with a guest account, we recommend that you link your account with other platforms to prevent possible account loss.
- The maintenance compensation will be provided once per account. Please note that the distribution may be slow due to network delays or other causes.
- The update gifts are valid to claim for 7 days. Please redeem them within this timeframe.

Thank you.
