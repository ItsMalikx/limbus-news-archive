Notice: Event Currency Error Withdrawal & Compensation

2025-02-12

------------------------------------------------------

Hello, this is Project Moon.

After the Feb. 13th Scheduled Update, any Event Currency that has been overdistributed or underdistributed due to the Feb. 6th Scheduled Update error will be withdrawn or compensated. Please refer to the text below for more information.

List
----

► An error where the event currency(Bloodied Scabbard) could not be obtained from the Mirror Dungeon - Yield My Flesh to Claim Their Bones Theme Pack

Managers who did not receive the event currency upon clearing a Mirror Dungeon will receive the event currency they are entitled to. This process will be notified via the in-game inbox to all affected managers.

► An error where event currency bonus for the LCB Regular Check-up Event(Amassed Data) was given when deploying Blade Lineage/Kurokumo Clan Identities

Excess event currency given out due to this error will be withdrawn. Please note that your event currency may go into the negatives if there aren't enough to be withdrawn. This process will be notified via the in-game inbox to all affected managers.

We apologize for the inconvenience.
