Issue Mitigation for Crashing Issues Upon Combat Entry on Certain Devices
-------------------------------------------------------------------------

Following the Unity version update on May 28th, 2026, we have identified a persistent issue on certain devices in which the game would crash upon entering combat.

After working with Unity's technical support team, we have identified that this issue may occur on some devices that meet the following conditions:
1. Devices equipped with Mali-G57 or Mali-G68 series GPUs
2. Devices where the Graphics API is set to "Vulkan" upon app launch
3. Devices where a specific Shader Compilation occurs when entering combat

We have confirmed that the crash is caused by an unidentified internal logic issue during GPU processing for the device environments listed above. To mitigate this issue, we will implement a filtering adjustment as part of the Jun. 18th Scheduled Update.

※ Work Details
The logic will be modified so that the Graphics API runs on "GLES" instead of "Vulkan" upon app launch for devices equipped with Mali-G57 or Mali-G68 series GPUs.
To quickly identify the cause of any related issues that may occur afterward, we will procure more test devices on which the crashing issue has occurred.

Furthermore, although the claim period for the "5/28 Scheduled Update Error" compensation was extended to Jun. 18th as previously announced on Jun. 1st, we believe there may be Managers who have yet to claim the compensation. As such, the claim period for this compensation has been extended by one additional week (until Jun. 25th).

► Extension of the 5/28 Scheduled Update Error Compensation Period
- Before: Claimable until Jun. 18th, 2026 10:00 (KST)
- After: Claim Period extended to Jun. 25th, 2026 10:00 (KST)

As for the measures outlined in our previous notice, we will provide a separate follow-up notice once all related issues have been fully resolved and the game can be played normally.

We sincerely apologize for the inconvenience caused by the delay in determining the cause of the issue.

Bug Fixes & Improvements
------------------------

► Fixed an issue where certain Skills of the Identity 'LCD OSIR Team Ishmael' would sometimes not activate
→ Affected Case 1 : Skill 1 'Rending Arts' - '[On Use] Gain +2 Poise Count' (Uptie 2 & 3)
→ Affected Case 2 : Skill 2-2 'To Claim Their Bones' - 'This Skill does not trigger Defense Skills' (After Uptie 2)
→ Affected Case 3 : Skill 3-2 'Even the Balance - Lucent Rippling Flame' - 'This Skill does not trigger Defense Skills ' (Uptie 4)
※ Regarding cases involving 'To Claim Their Bones' and 'Even the Balance - Lucent Rippling Flame': While these Skills did not trigger Clashable Defense Skills as intended, we had identified an issue where they would trigger non-Clashable Defense Skills.

► Fixed an issue where 'LCD OSIR Team Ishmael' Keyword 'Bearing of a Salsu' did not work as intended
→ Relevant Effect : Lose 1 Stack when an allied Blade Lineage Identity is defeated
- Before : The Keyword would lose 1 Stack even when a non-Blade Lineage Identity was defeated
- After : The Keyword will now lose 1 Stack only when a Blade Lineage Identity is defeated, as described

► Fixed an issue where 'Prisoner Transport Arrangements' Keyword, used by 'S Corp. Ch'unokkun Hong Lu', did not behave as described
→ Relevant Effect : On Hit against enemies that have Trussed [Hong Lu], inflict 1 Bleed and gain 1 Poise (2 Skills per turn)
- Before : This effect triggered only when ''the Coin confirmed to strike the first hit'', hit.
- After : The effect will trigger every time a Coin hits, as described

► Fixed an issue where, when losing a certain combat Encounter while 'LCE E.G.O:: AEDD Gregor' has 'Self-charge', the unit would survive with 1 remaining HP instead of being defeated

► Fixed issues where 2 Identities, 'LCE E.G.O::Ardor Blossom Star Faust' and 'The House of Spiders: The Middle Nursefather Outis', would have certain visual effects incorrectly applied
→ Relevant Effect 1 : An issue where certain effects would not render as intended
→ Relevant Effect 2 : An issue where, in 'Timekilling Time' Stages, color-changing effects would not apply when hovering over the affected Identities with a cursor

► Applied level adjustments to certain enemies featured in combat Encounters of Ch. 9.5 'Mnestic Experience'
- Before : Level 60
- After : Level 50
※ This change has been applied for story-related reasons. To maintain a consistent gameplay experience for our managers, however, additional adjustments to Offense Level and Defense Level will be applied.

► Fixed an issue where, when enemy roster changes during combat Encounters of Ch. 9.5 'Mnestic Experience', the switched enemies' identification codes and Risk Levels would appear incorrectly

► Adjusted Passives for certain enemies appearing in the boss Encounter of Ch. 9.5 'Mnestic Experience' to be unlocked for viewing as soon as they enter the Encounter

► Fixed an issue where, when using the continue function in main story Dungeons of the Fathoms, the Identities' HP would not fully heal
