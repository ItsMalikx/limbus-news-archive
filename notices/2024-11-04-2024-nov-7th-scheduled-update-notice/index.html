2024, Nov. 7th Scheduled Update Notice

November 4, 2024
Balance

Greetings, Dear Manager.

The server will enter scheduled maintenance from 10:00 [AM] through 12:00 [PM] on Nov 7th, 2024 (KST).

Please make note of the maintenance schedule; we recommend that you refrain from entering combat or making in-app purchases and close the application before maintenance begins so that no data is lost.

Please refer below for details about the update.

Bug Fixes & Improvements

▶ Fixed an issue where, under specific conditions, Skills could be reused

▶ Added relevant Trait Keywords to the following Enemies & Identities
※ Added Trait Keyword: La Manchaland

▶ (EN Only) Fixed an issue where Yi Sang E.G.O - Dimension Shredder's [Before Attack] effect's max damage cap was missing a "%" in its description

▶ Fixed an issue where, in Focused Encounters, 'If the target is <Trait Keyword>…' effect did not activate
※ e.g. Fanghunt Office Fixer Hong Lu's Uptie 4 Skill 2's "If the target is a <Bloodfiend> or a <Bloodbag>, Coin Power +1"

▶ Fixed an issue where Sinner Don Quixote could be slotted in as a Backup Unit in Stage 7-36

▶ Fixed an incorrect description for a Boss enemy's Passive in Stage 7-36
※ Affected Passive: If we can be freed from this excruciating sickness
- Before : On Hit, if the target has Bleed, heal Part and Core by 40% of the HP damage dealt.
- After : On Hit, if the target has Bleed, heal Part and Core by 40% of the damage dealt.

▶ Fixed an issue where, against a certain Boss in Stage 7-36, the status effect VFX would trigger twice after Clash

▶ Fixed an issue where the enemy placement loaded incorrectly in a certain node within Stage 3.5-10

▶ Fixed an issue where certain lettering VFX(lyrics) won't load properly

▶ Fixed a possible UI issue when attempting to view the Uptie Story of an Identity that shares the story category with Wild Hunt Heathcliff while not owning Wild Hunt Heathcliff

▶ Fixed an issue where, in Canto 7 section of Theaters, certain story thumbnails were incorrectly applied to the game

▶ Improved UI interactivity within the Mailbox

▶ Adjusted blurriness in Mirror Dungeon to improve visibility for description windows
※ Relevant areas
(1) Description area for the list of Starter Buff effects
(2) Description area for the effects of selected E.G.O Gifts in the list of starting E.G.O Gifts

We apologize for the frequency of issues that have been occurring after the Canto 7 Update.
We are preparing the following solutions to issues occurring within the game.

1. Reduce Error Occurance Frequency
- When making corrections to the in-game logic, we are setting certain parameters so that issues that have occurred in the past won't occur again
- Cross-examination of new systems and UI logic by adding logic for exceptions

2. Measures in Case of Errors
- Set a list of priorities by severity of errors and issues
- Enhance the logging system so that we can identify the magnitude of the issue caused by the error, and address it appropriately

We will try our best to provide you a more stable gaming experience.

We sincerely apologize for the inconvenience.

Maintenance & Application Update Compensation

- Content: Lunacy x300
- Recipients: All users whose game accounts were created before 10:00 Nov. 14th, 2024 (KST)
- When: After Nov. 7th, 2024 (Thu) 12:00 (KST)
- Can be claimed once per account

Maintenance Compensation can be claimed until Nov. 14th (Thu) 2024, 10:00 (KST) via the in-game Mailbox. (Mail available for 7 days)

Notes

- Please update your game client to the newest version on the respective store (Google Play/App Store/Steam).
- Forcibly shutting down the game while it is downloading resources may cause the download to fail, so please be careful not to close the application during the download.
- You will not be able to play <Limbus Company> during maintenance. Please understand.
- The maintenance schedule may suddenly change depending on the status of maintenance. If such a change occurs, we will let you know in a follow-up notice.
- A resource download may be prompted after the build update. If you're using a mobile device, it is recommended to proceed with a Wi-Fi connection.
- If you're playing with a guest account, we recommend that you link your account with other platforms to prevent possible account loss.
- The maintenance compensation will be provided once per account. Please note that the distribution may be slow due to network delays or other causes.
- The update gifts are valid to claim for 7 days. Please redeem them within this timeframe.

Thank you.
