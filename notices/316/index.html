Notice: Nov. 28th Scheduled Update Hotfix

November 28, 2024

We have identified the following issues in our Nov. 28th Scheduled Update.

A hotfix will be deployed at 19:30 today to fix the following issues.

Hotfixes do not require a separate client update, and can be applied upon restarting the game. Please note that additional downloads may occur.

[Issues to be addressed with the Upcoming Hotfix]

- Mirror Dungeon: An issue where, in certain Encounters, a certain effect unique to Ishmael activates
- Mirror Dungeon: An issue where certain Encounters have unmatched BGM
- Mirror Dungeon: An issue where the Grace of Stars - Binary Star-Shop has a typo in its description
- E.G.O Gifts: An issue where "Layered Bandages+" is missing its text
- E.G.O Gifts: An issue where T-1 Perpetual Motion Machine has an unnecessary highlighted text over the 'Unique Charge' text

[Mirror Dungeon Changes with the Upcoming Hotfix]

1. Add 30 'Starter Buff Cost'(the currency used to purchase the Grace of Stars; temporary name) regardless of the loadout's Rest Bonus value
- The said change is a temporary effect; it will be replaced with the 24.12.05 (KST) Scheduled Update.

2. Adjusted the 30+ Rest Bonus Passive Effect
Before: Upon Floor 2 entry, select a Tier 2 Shop-only E.G.O Gift of your choice
After: Starting Cost upon entry +100
- The said change is a temporary effect; it will be replaced with the 24.12.05 (KST) Scheduled Update.

3. Adjusted the 50+ Rest Bonus Passive Effect
Before: Upon Floor 3 entry, select a Tier 3 Shop-only E.G.O Gift of your choice
After: Starting Cost upon entry +150
- The said change is a temporary effect; it will be replaced with the 24.12.05 (KST) Scheduled Update.

4. The number of purchasable E.G.O Gift from Shops will be increased from 3 to 4

5. Adjusted the number of enemies in Encounters where there are too many enemy Slots compared to ally Slots

6. E.G.O Gift Enhancement Cost Reduced
The Costs have been reduced by approximately 40% across the board.

7. Identity Skill Replacement Cost Reduced
► Skill 1 -> Skill 2

► Skill 1 -> Skill 3

8. Shop Refresh Cost Reduced
► Normal Refresh

► Keyword Refresh

The following are Known issues that will be fixed with the next Scheduled Update.

[Known Issues]

- Mirror Dungeon: An issue where certain enemies have incorrect levels
- Mirror Dungeon: (EN, JP Only) An issue where a certain UI Text is missing the translations
- (PC Only) An issue where the shortcut keys don't activate properly in the Combat Menu
- An issue where 'La Manchaland' Identities activate in incorrect Skill VFX levels
- An issue where, under certain circumstances, Yi Sang E.G.O - Fell Bullet animation plays incorrectly

We sincerely apologize for the inconvenience.
