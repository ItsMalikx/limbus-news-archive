Upcoming Canto 10 Improvements

[Main Story Canto 10 Control Scheme & Feel Improvements]
As we shared in our Sep. 17th and 18th notices, game control scheme improvements will be implemented for Main Story Canto 10.

1. Combat and Interaction Improvements
- Reduced the attack speed of some enemies in certain stages
- Reduced the length of recovery frames for movement after using a Basic Attack
- Enabled movement inputs in the middle of the Basic Attack animation if it did not hit a target
- Reduced the delay when making directional inputs
- Expanded object interaction range so that the player only has to be near the interactable object, and no longer has to look directly at it
- (Mobile only) Adjusted the virtual mobile control UI images so they don't overlap with touchscreen areas

2. Settings - Sisyphe Mode Added
- A toggleable Lighting Mode ON/OFF setting is added. This option enables brightness adjustment options for the game mode.
- (Steam - PC Only) Key Mapping setting is added. Through this menu, the user can assign different keys for each function in this game mode.
- (Mobile Only) A toggleable Directional Movement Correction setting is added. This option enables movement toward the nearest tile to the intended direction when the user makes a diagonal input on the virtual joystick.
- (Mobile Only) A toggleable Auto-Sprint Timer setting is added. When toggled on, the game will engage Sprint mode a few seconds after pushing the virtual joystick into the Sprint zone, instead of engaging it immediately.
- (Mobile Only) A Directional Change Threshold Adjustment setting is added. Through this option, the user can decide the sensitivity of the virtual joystick for determining the threshold at which the controlled character changes direction mid-movement.
- (Mobile Only) Virtual Joystick Sensitivity setting is added. Through this option, the user can decide the range of the joystick movement radius down to exact percentages to determine the following elements: V. Joystick Walk Threshold, V. Joystick Walk/Sprint Range, and V. Joystick Sprint Threshold.
(1) V. Joystick Walk Threshold: This setting adjusts the radius % to which the virtual joystick must be pushed for the controlled character to start walking.
(2) V. Joystick Walk/Sprint Range: This setting adjusts the range of radius to which the virtual joystick can be pushed to maintain the controlled character's walking/Sprinting behavior.
(3) V. Joystick Sprint Threshold: This setting adjusts the radius % to which the virtual joystick must be pushed for the controlled character to start Sprinting.
※ All settings save for "Key Mapping" can be accessed in the following menu: Settings -> Game Settings -> Sisyphe
※ Key Mapping can be accessed in the following menu:
Settings -> Game Settings -> Key Mapping
※ When "Lighting Mode" is toggled ON, "Adjust Brightness" and "Limit Peak Brightness" levels can be customized.

[Luxcavation #10 Adjustments]
We have received various feedback regarding the high difficulty of Luxcavation #10, updated Sep. 17th. Therefore, Luxcavation #10's difficulty will be adjusted with the Sep. 24th Scheduled Update.

1. Slash Luxcavation #10

- Increased frequency of weaker Skills for featured enemies

2. Pierce Luxcavation #10
- Lower HP and additional Stagger Threshold for featured enemies
- Increased frequency of weaker Skills for featured enemies
- Lower Skill Power for certain Skills for featured enemies
※ Lowered Skill Power applies to enemies featured in the Shadowed Battles in Canto 10 as well.

3. Blunt Luxcavation #10
- Lower HP and additional Stagger Threshold for featured enemies
- Increased frequency of weaker Skills for featured enemies
- Lower Skill Power for certain Skills for featured enemies
※ Lowered Skill Power applies to enemies featured in the Shadowed Battles in Canto 10 as well.

[Fixed an Issue Where Lighting Effects Malfunction on Certain Devices]
- Cause: Certain Intel Integrated GPU graphic drivers were unable to process the lighting system, which caused the game to appear abnormally dark.
- Solution: The game will now automatically detect the local graphics environment and employ a different lighting implementation on Intel Integrated GPUs.
- Note: Updating your graphic driver will provide a more stable experience. If this issue persists after the update, please submit your Playerlog through our Customer Service email.
