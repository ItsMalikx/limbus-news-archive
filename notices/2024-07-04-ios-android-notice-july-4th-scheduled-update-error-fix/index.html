    [(iOS, Android) Notice: July 4th Scheduled Update Error Fix]

    July 4, 2024

    Hello,
    This is Project Moon.

    The new Client update(1.51.1) with the urgent bug fixes for the Client version 1.51.0 has been deployed to each respective store.
    You can download the Client updates via each platform store and confirm that the update was successful by checking the bottom right corner of the screen. It should say Version 1.51.1.
    Please note that continuing with the 1.51.0 version without updating it with the latest Client will cause the following issues.
    Version 1.51.0 will become inaccessible after July 5th (FRI), 18:00 (KST).

    ※ Please note that the deployment time may vary depending on your time zone.
    If the platform store does not show that the update is available, then please confirm again later.

    [Version 1.51.1 Changelog]

    - Fixed an issue where, in Refraction Railway Line 4 Section 1 Wave 1, if an enemy spawned mid-Encounter is killed by the "Burn" effect, the game softlocks
    - Fixed an issue where certain enemies in the Refraction Railway Line 4 play special Identity voicelines
    - Fixed an issue where winning the final battle of Canto V Story Dungeon causes the game to softlock
    - Fixed an issue where Stage 6-44 enemy pattern does not work as intended

    We sincerely apologize for the inconvenience.
