Important Notes and Improvements Following Unity Version Upgrade

May 25, 2026
Balance

Hello, this is Project Moon.

To provide a more stable game service and comply with store policies, Limbus Company will be upgraded to the latest version of the Unity Engine with the May 28th, 2026 Scheduled Update.

Resource downloads will be required once the engine update is deployed. Additionally, the minimum supported OS requirements will be raised, potentially restricting access on certain devices.

Please refer to the details below for more information.

Unity Engine Version Upgrade Schedule

The Unity version upgrade will be applied starting with game version 1.106.0, scheduled to be updated on May 28th, 2026.

Major Improvements

1. Compatibility with the latest devices and operating systems
- With the game engine upgraded to the latest version, compatibility has been improved for the latest PC environments and newer smartphone operating systems.

2. Overall improvements to in-game speed and performance
- With the new engine version's fundamental optimizations, Managers may notice improvements in loading speed, frame stability, UI transitions, etc., depending on individual device specifications and gameplay environment.

Notice on Restrictions for Certain Devices

※ To prevent account loss, Managers who are playing Limbus Company with a Guest account on any of the systems listed below are required to link their account to a Google, Apple, or Steam account.

AOS (Android OS)
- Minimum OS Requirement: Android 8.0 (API 26) or higher. Game installation and launch will no longer be possible on smartphones running Android 7 or earlier versions.

iOS
- Minimum OS Requirement: iOS 13 or higher (A8 chipset or higher). Game installation and launch will no longer be possible on iPhone 6 or older models.

Steam
- Minimum OS Requirement: Windows 10 Version 21H2 or higher.
- As official support for Windows 7 and 8 has been discontinued, and the engine does not support running on these systems, the game will crash upon launch on Windows 7 and 8 and become inaccessible.

Graphics API and Performance
- Unity 6 is optimized for Vulkan (AOS), Metal (iOS), and the Universal Render Pipeline (URP).
- On devices that only support OpenGL ES, graphics may not display properly, or performance may be degraded.
- On Steam, the graphics API will prioritize DirectX 12. If DirectX 12 cannot be used, the game will use DirectX 11 as an alternative. However, when using DirectX 11, errors may occur during graphics rendering.

Resource Redownloads by Platform

- With the deployment of the Unity version upgrade, each platform will redownload resources adapted to the new game engine.
- As the download size is very large, Managers playing on mobile are advised to use a Wi-Fi connection for stable installation and to reduce data charges. Download sizes are as follows:

Steam: Approx. 14 GB
Android (AOS): Approx. 11 GB iOS: Approx. 10 GB

Follow-up Measures After the Unity Version Upgrade

- Please note that the Unity version upgrade, to be applied on the game with the May 28th Scheduled Update, may bring various unexpected errors on the day of the update.
- Although Project Moon's development team is carefully monitoring the overall server and systems environment as thoroughly as possible, some issues may still occur that were not discovered in advance.
- Should you notice any abnormal game behavior or experience any inconvenience following the update, please reach out to the Limbus Company Customer Support Center with the relevant details. Upon ticket receipt, we will do our utmost to check and address the flagged issue as soon as possible.

Please direct any bug reports for Limbus Company to the email below:
limbussupport+bug@projmoon.com

Thank you.
