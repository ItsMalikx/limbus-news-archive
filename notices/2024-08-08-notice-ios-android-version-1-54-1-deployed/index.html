    Notice: iOS, Android Version 1.54.1 Deployed

    August 8, 2024

    Hello,
    This is Project Moon.

    A new Client Version(1.54.1) with fixes for the issues that were identified in Version 1.54.0 has been deployed on each respective store as of Aug. 8th (THU) 20:30(KST).
    Please download the updates from the platform of your choice, and you can verify that by checking the bottom right corner of the screen to see if it displays Version 1.54.1.
    Please note that playing the game without downloading the update will cause the following issues.
    Version 1.54.0 will no longer be accessible starting Aug. 9th(FRI) 11:00(KST).

    ※ Plase note that there may be differences in deployment times depending on your location and device.
    If your platform store does not display an option to update, then please check again at a later time.

    Version 1.54.1 Changelog
    - An issue where the game softlocks at Stage 5-18
    - An issue where defeating every enemy at once under a specific condition in a Mirror Dungeon - Chain Battle causes the Encounter to end in a defeat, making it unable to proceed to the next Stage
    - An issue where substituted Backup units do not gain additional Skill Slots in Regular Encounters Chain Battles
    - An issue where VFX for the Passive of an enemy appearing in 6.5-2 lingers even after the Passive ends
    - An issue where, in the Nominable Egoshard Crate opening UI, selecting and deselecting the Sinner's shards doesn't actually deselect the Sinner
    - An issue where translations for the text in the popup window for 'Clear Selection' option in the Loadout Menu are not applied

    We sincerely apologize for the inconvenience.
