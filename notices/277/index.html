2024, September 12th Scheduled Update Notice

September 9, 2024
BalanceRewards

Greetings, Dear Manager.

The server will enter scheduled maintenance from 10:00 [AM] through 12:00 [PM] on Sep. 12th, 2024 (KST).

Please make note of the maintenance schedule; we recommend that you refrain from entering combat or making in-app purchases and close the application before maintenance begins so that no data is lost.

Please refer below for details about the update.

Google Play Full Moon Campaign Commemorative Package Notice

To commemorate Google Play's Full Moon Campaign, the following three upgrade resource packs will be sold at the shop.

※ The new Full Moon Campaign Commemorative Packages will be purchasable via Paid Lunacy regardless of the platform at the in-game Lunacy Shop.

▶ Sales Period : 2024/09/12 12:00 ~ 2024/09/26 10:00 (KST)

▶ Package Contents
(1) Full Moon 2024 Commemorative ID Upgrade Pack
- Contents: Takeoff Module - ID Uptie x1, Identity Training Ticket IV x80
- Price: Paid Lunacy 2500

(2) Full Moon 2024 Commemorative E.G.O Upgrade Pack
- Contents: Decaextraction Ticket x3, Takeoff Module - E.G.O Spinning [WAW] x1
- Price: Paid Lunacy 4150

(3) Full Moon 2024 Commemorative Complete Pack
- Contents: Decaextraction Ticket x4, Takeoff Module - ID Uptie x1, Takeoff Module - E.G.O Spinning [WAW] x1, Identity Training Ticket IV x80, Threads x100
- Price: Paid Lunacy 6750

※ Using the Takeoff Module - ID Uptie raises the selected Identity's Uptie Tier to 4.

※ Using the Takeoff Module - E.G.O Spinning [WAW] raises the selected E.G.O's Threadspinning tier to 4. (Usable only on E.G.Os WAW Level or lower)

Bug Fixes & Improvements

▶ Fixed an issue where, in certain conditions, passive effects that recovers from Staggered can recover from forced Stagger effects

▶ Fixed an issue where the character sprite doesn't load correctly if Wild Hunt Heathcliff was affected by a forced Stagger effect just as he is dismounting from Dullahan

▶ Fixed an issue where a certain Sinner acts out of character in a certain Choice Event in Stage 3-22
※ Relevant Choice Event : Tread the heated path.
※ Relevant Sinner : Don Quixote

▶ Fixed an issue where, under certain circumstances, more than intended number of Announcers could be equipped

▶ Fixed an issue where certain effects of the debuff - Impending Ruin did not activate properly in Focused Encounters
(1) The 'Change Panic Type' effect did not activate against units with SP
(2) The effect would expire immediately from the affected enemy even when it has 2 or more Stacks

▶ Fixed an issue where certain effects of the debuff - Echoes of the Manor did not activate properly in Focused Encounters
※ This issue occurred with the Sep. 5th Scheduled Update and did not exist in the game prior.
※ Relevant Effect : 50% chance to gain 1 Sinking Count when gaining Sinking Potency or Count from Skill or Coin effects

▶ Fixed an issue where, in Focused Encounters, the Part HP bar UI does not update real-time in Focused Encounters
※ This is a visual-only issue, and the actual damage dealt was unaffected.

▶ Fixed an issue where, under certain circumstances, an Event Mission in 'Noon of Violet' would sometimes not be completable
※ Relevant Mission : Defeat Grant Us Love with Training Team Captain

▶ Fixed an issue where defeating an enemy with a Status Effect damage in the 'Noon of Violet' Event Encounter does not count toward the defeated enemy tally
※ This did not affect the Missions(challenges); the missions were tallying them correctly.

▶ Fixed an issue where, in Focused Encounters, a new summoned unit or a summoned unit would cause their UI to glitch upon Turn Start

▶ Fixed an issue where obtaining an Identity or E.G.O through the Battle Pass or through the Inbox while the Window UI is set to the Manager Ticket would cause the Ticket resources to overlap with the acquisition cutscenes

▶ Fixed an issue where Growth -> Weekly -> Weekly EXP Pack's icon did not match the actual contents of the Package
- Before : Identity Training Ticket III was a part of icon
- After : Deleted the Identity Training Ticket III from the icon because it is not a part of the Package
※ This does not change the actual contents of the Package.

▶ Fixed an issue where healing or losing SP in the middle of a multi-coin E.G.O Skill would not show the relevant number popups

▶ (JP Only) Fixed various typos
(1) Fixed typos in the buff 'Reload' effect description
(2) Fixed typos in certain Choice Event texts for the Mirror Dungeon Floor Theme Pack 'The 4th Walpurgis Night'
(3) Fixed a typo in the name of the E.G.O Gift 'Filial Love'
(4) Fixed typos in Identity Stories where certain characters had incorrect affiliations/titles

Known Issues

▶ (Android) Dispenser - An issue where selecting Identities located in certain screen areas from the Identity List would not register as an input

▶ (Android) Fixed an issue where a Choice Event image resource does not load in the Choice Event that plays during the 'Noon of Violet' Hard difficulty

Notes

- Please update your game client to the newest version on the respective store (Google Play/App Store/Steam).
- Forcibly shutting down the game while it is downloading resources may cause the download to fail, so please be careful not to close the application during the download.
- You will not be able to play <Limbus Company> during maintenance. Please understand.
- The maintenance schedule may suddenly change depending on the status of maintenance. If such a change occurs, we will let you know in a follow-up notice.
- A resource download may be prompted after the build update. If you're using a mobile device, it is recommended to proceed with a Wi-Fi connection.
- If you're playing with a guest account, we recommend that you link your account with other platforms to prevent possible account loss.
- The maintenance compensation will be provided once per account. Please note that the distribution may be slow due to network delays or other causes.
- The update gifts are valid to claim for 7 days. Please redeem them within this timeframe.
