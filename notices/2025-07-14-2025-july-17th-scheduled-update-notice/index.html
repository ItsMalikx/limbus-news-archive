E.G.O Gift Adjustments and Text Corrections

※ Certain E.G.O Gifts will have their effects and texts adjusted.
※ The following adjustment descriptions are all base-level, un-enhanced versions of E.G.O Gifts.
※ We have only noted the parts of the E.G.O Gifts that are changed or added; any unlisted effects have not been adjusted.

1. Text Corrections
※ These are E.G.O Gifts with descriptions that are getting changed to match the actual effects.

▶ A Drop
- Before : Before using Skills that consume Bloodfeast, if the target has 30+ Bleed Potency...
- After : Combat Start: if the target getting attacked by an Identity that consumes Bloodfeast has 30+ Bleed Potency...

▶ Ruin
- Before : When inflicting Rupture Potency with Skill effects, inflict 2 Rupture Potency and +1 Rupture Count against the target
- After : When inflicting Rupture Potency or Count with Skill effects, inflict 2 Rupture Potency and +1 Rupture Count against the target

▶ Nightvision Goggles
- Before : This Gift activates when an ally has 15+ Charge Count at Turn Start
- After : This Gift activates when an ally has 15+ Charge Count at Turn Start (including 'Unique Charge')

▶ Miniature Telepole
- Before : After Attack with a Skill Attack that consumed 7+ Charge Count on self: if the target is defeated, gain (Charge Count consumed by the Skill / 4) Charge Count
- After : After Attack with a Skill Attack that consumed 7+ Charge Count on self: if the target is defeated, gain (Charge Count consumed by the Skill / 4) Charge Count (including 'Unique Charge')

2. Effects Adjustments
※ Certain E.G.O Gifts will now count or activate for 'Unique Charge' as well.
※ With this adjustment, each E.G.O Gift will be added with the new description (including 'Unique Charge').
※ Affected E.G.O Gifts : T-5 Perpetual Motion Machine, Insulator, Charge-type Gloves(Near-light Superbattery), UPS System, Lightning Axe

3. Text Adjustments
※ Texts for certain E.G.O Gifts will be adjusted.

▶ T-1B Octagonal Bolt
- Before : Turn Start: all allies gain ((Charge Count + 'Unique Charge') / 10) Damage Up. (max 2, rounded up)
- After : Turn Start: all allies gain (Charge Count/ 10) Damage Up. (max 2, rounded up; including 'Unique Charge')

▶ T-1 Perpetual Motion Machine
- Before : Turn Start: all allies gain ((Charge Count + 'Unique Charge')/5 +1) Damage Up (max 9, rounded up)
- After : Turn Start: all allies gain ((Charge Count)/5 +1) Damage Up (max 9, rounded up; including 'Unique Charge')
