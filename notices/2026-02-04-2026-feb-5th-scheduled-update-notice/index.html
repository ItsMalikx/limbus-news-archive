Bug Fixes & Improvements

▶ Fixed an issue where the special animation for Lobotomy E.G.O::Lantern Don Quixote's Skill 3 did not play even though the prerequisite condition was met

▶ Fixed an issue where the effect "The Middle Identities gain Min Speed +1 and Max Speed +1 for the Encounter" from the E.G.O Gift "Everlasting Chains of Bond" did not trigger

※ Other effects of "Everlasting Chains of Bond" were functioning as intended; only the aforementioned effect was affected and will be fixed.

▶ (EN Only) Fixed an issue where some dialogue text displayed when using Heathcliff's E.G.O "Move-in Reg." extended beyond the screen bounds due to excessive length

▶ Fixed an issue where the text was displayed in an incorrect order on the Uptie screen of Outis's E.G.O "I'll Go for Scissors. How 'Bout You?"

※ The skill effect is functioning as intended as "On Unopposed Attack: Does not activate this Skill's [On Hit without Cracking] effects."

However, as the text was shown as "[On Hit without Cracking] On Unopposed Attack: Does not activate this Skill's effects," the order of the text will be corrected.

▶ Fixed an issue where UI indicators appeared as if certain effects that increase or decrease Base Power or Final Power based on Sin Affinity and Attack Types triggered even though the Skills used did not correspond to the prerequisite Sin Affinity or Attack Type

※ The effects were not actually applied; only the UI was displayed incorrectly and will be fixed.

▶ Fixed an issue where using an E.G.O Skill below Uptie 3 in Stage 9-50 caused an incorrect background image from another stage to appear

▶ Fixed an issue where certain effects did not display correctly on specific enemies appearing in Stage 9-30 and Stage 9-49

▶ Updated and polished English translation for Canto 2

▶ Fixed an issue where, under certain conditions, the Coin-flipping animation played when "Reuse Coin" effects were activated during combat

▶ Fixed an issue where the "Enemy Killed" voiceline entry was missing from LCB Sinner Gregor's voiceline list

▶ (EN Only) Changed the Manager Ticket customization word for Heishou Pack - Si Branch Rodion due to translation that might potentially overlap when obtaining the Identity Lobotomy E.G.O::Lamp Gregor that features a similar word in Korean

※ Changed text: Beast -> Animal

Known Issues

▶ An issue where the text for Jeong's Office Rep. Ishmael's "Base Power Up" effect, which activates upon "forming a Hand", appears even when no Hand has been formed.

※ This does not actually activate the effect; this is a visual-only issue where the UI element loads when it should not. As this issue was not fixed when the issue where "UI indicators appeared as if certain effects that increase or decrease Base Power or Final Power based on Sin Affinity and Attack Types triggered even though the Skills used did not correspond to the prerequisite Sin Affinity or Attack Type" was fixed, the fix will be applied on our next Scheduled Update.

▶ An issue where, when the corresponding Sin Affinity Power Up effect was activated when using Evade Skills, the relevant UI elements do not load

※ The Power Up effects are activating correctly; this is a visual-only issue where the UI text does not appear when it should.

▶ An issue where, when using E.G.O Skills that may be affected by "The Middle Styled Augmentation Tattoos" effect, the relevant UI elements do not load

※ The effect is activating correctly; this is a visual-only issue where the UI text sometimes does not appear when it should.
