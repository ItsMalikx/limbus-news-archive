    Notice: Error 70402 Login Failure After 5/28 Update and Follow-up Measures

    June 4, 2026

    Hello, this is Project Moon.

    After the update on May 28th, 2026, we have identified an issue in which Error Code 70402 appears when launching the game, preventing access.

    This issue was resolved through a server data correction on Jun. 4th, 2026, 13:44 (KST).
    Please refer below for more information.

    [ Issue Identified ]

    - An issue where, following the May 28th Scheduled Update, Error 70402 would pop up upon launching the game, resulting in login failure

    [ Cause of the Issue ]

    - A data conflict occurred with certain files of the Announcer Preset expansion function included in the May 28th Scheduled Update, causing the error pop-up and login failure

    [ Issue Fix ]

    - Data migration was performed on Jun. 4th, 2026, 13:44 (KST) for Managers affected by the issue (total affected users: 995)

    [ Follow-up Measures ]

    - We are currently reviewing possible measures for Managers who, after the Ver. 1.106.1 update on AOS, encountered either a black screen upon launching the game or a loading screen after entering a combat stage, preventing game progression.

    We will inform you via a separate notice once all related issues have been fully resolved.
    We kindly ask for your patience as our teams analyze and resolve the issue.

    We sincerely apologize for the inconvenience.
