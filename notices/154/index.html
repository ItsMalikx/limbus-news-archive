2. Gradual Main Story & Battle Pass Updates

No apparent changes have been made, however, and the resources will appear as usual. Additional downloads will occur in addition to the newly added resources.

We apologize for the disturbance these changes may cause.

Major Changes

1. Detailed Skill Info UI summary option added
Before : Every activated buffs and effects will show
After : Show only 5 of the activated buffs and effects. If there are more than 5, only the number of additional activated effects will appear.

- Intent: There was an issue before where, if too many buffs and effects were activated, they would clutter the screen and harm visual clarity. This made it difficult to focus on tide of the combat itself, so we have added an option to mitigate that issue.

Bug Fixes & Improvements

▶ Adjusted Story Dungeon Identity Choice display orders.
Now, Sinner portraits with chances will appear only after the Choice description text is displayed.

※ We believed that it appeared awkward to show the chances before knowing what the descriptions were; so we have adjusted the display orders so that the portraits will appear after the descriptions.

▶ Fixed an issue where toggling the "Display detailed info UI in Combat Phase" option off still showed remaining VFX

▶ Fixed a certain enemy's Skill effects for the Skill "..." from Canto V
- Before : Apply 4 Tremor
- After : Apply 4 Tremor Count

▶ Updated the loading screen illustration that appears after clearing Main Story 5-35

Known Issues after Nov. 30th Update

▶ An issue where, in the User Info-Company tab, Identity Select UI highlight VFX does not disappear

▶ An issue where the Detailed Info UI during an Encounter sometimes displays misaligned images

Bug Fixes & Improvements

▶ Fixed typos in The Middle Little Sister Don Quixote's Identity Story.

▶ Ryōshū E.G.O: Red Eyes - Fixed an issue where it had an incorrect resistance value to 'Lust' affinity
- Before : 0.75 (Endure)
- After : 0.5 (Ineff.)

※ This E.G.O's affinity resistance was applied as 0.75 instead of 0.5, which is the correct E.G.O affinity resistance value for TETH E.G.Os.

▶ Meursault E.G.O: Chains of Others - Fixed an issue where certain Threadspinning Tier 4 Coin effects were mislabeled
- Before: [Heads Hit] Gain 2 Protection next turn
- After: [On Hit] Gain 2 Protection next turn

※ This E.G.O's Threadspinning Tier 4 Coin effect was labeled incorrectly as [Heads Hit] when its actual effect was [On Hit].
The actual effects of this E.G.O is unchanged; this only changes the text to fit the actual effect.

▶ Fixed an issue where certain BGM would not play during Main Story 5-29 Combat Encounter

▶ Fixed an issue where texts for a certain enemy's buffs would not appear during Main Story 5-30 Combat Encounter

▶ Fixed an issue in the Story Dungeons where, if the team is wiped at more than 0 SP, or if the player uses the in-game menu to return to the Save Point at more than 0 SP, SP did not reset to 0.

▶ Deleted unused text from Choice Success rate displays
- Text: 5% Chance of Success

※ We have identified that an outdated text from our development period for the Choice events still remained within the game.
Because the effect as written on that text is not being applied in the game, that text should have been deleted; but due to a miscommunication in our development process, that particular text was not erased. Thus, we have deleted it with this Update.
We apologize for letting this unused text be displayed in the game for so long.
