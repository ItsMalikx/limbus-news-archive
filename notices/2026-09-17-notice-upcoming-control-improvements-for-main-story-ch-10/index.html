    Notice: Upcoming Control Improvements for Main Story Ch. 10

    September 17, 2026
    Main StoryBalance

    Hello, this is Project Moon.

    Since the release of Main Story Canto 10 (Part 1) on September 17th, 2026, we have received a wide range of feedback from Managers regarding the ingame controls in a certain stage.

    We sincerely apologize for the inconvenience caused by the controls not feeling as smooth or responsive as they should.

    Based on the feedback we have received, we will be making several control improvements to a certain Stage in Canto 10 in the next Scheduled Update.

    Please refer to the below for details.

    [Upcoming Control Improvements]
    ※ Unless otherwise marked as (Mobile), the following changes will also apply to the Steam version.

    1. Combat and Interaction Improvements

    - Reduced the attack speed of some enemies in certain stages
    - Reduced the length of recovery frames for missed attacks
    - Reduced the attack animation delay when moving in the middle of an attack animation
    - Reduced the delay when making directional inputs
    - Expanded object interaction range so that the player only has to be near the interactable object, and no longer has to look directly at it

    2. Other Improvements

    - (Mobile only) Toggleable fixed joystick location option
    - Toggleable directional movement correction function
    - Adjustable input delay for directional inputs
    - Adjusted the virtual mobile control UI images so they don't overlap with touchscreen areas
    - Add map brightness adjustment options

    All the above improvements will be deployed with the next Scheduled Update (Sep. 24th).
    Please note that we will continue to improve the controls of this game mode, in addition to what has already been shared above.

    We will try our best to ensure a smoother gameplay experience for our users.

    We sincerely apologize for the inconvenience.
