Fixes to the "Judgment!" Skill of Haute Couture::Le Noir Brand Manager Don Quixote

We have identified implementation and text errors concerning the "Judgment!" Skill-related effects in the Passive "The Lord's Will and Values Be With Us..." and plan to fix them.

We apologize for having to announce multiple corrections to an Identity so soon after its release. We will take greater care to prevent similar issues.

Please refer below for details.

[Identified Issues]

The effect concerned was designed so that Don Quixote would perform an Unopposed Attack with the "Judgment!" Skill "before another allied Le Noir Identity used an Attack Skill or Counter Skill against an enemy". However, we identified the following issues:

1. The in-game text says "Before Attack" rather than "Before Use", which is the actual activation timing

2. The activation check is based only on Attack Skills assigned during the Chaining Phase. As a result, the effect does not activate for Skills used through Assist Attacks, Passive effects, or other means

3. The effect does not activate before Counter Skills, Clashable Counter Skills, or Attack Skills converted from Defense Skills at Combat Start

4. The Passive can activate even when the allied Le Noir Identity is unable to act and cannot use its Skill

[Cause of the Issue]

The effect was initially designed to activate only before the use of an Attack Skill. However, during testing, we decided to expand it to activate before the use of Counter Skills and Attack Skills converted from Defense Skills as well. While revising the description to cover these additional conditionals, we used the ambiguous phrase "Before Attack" —a different point in the attack sequence from "Before Use", which is the current activation timing. In addition, the expanded scope was not reflected in the in-game implementation. The activation check also remained based solely on Skills assigned during the Chaining Phase. Our review process did not catch these discrepancies between the intended design, implementation, and text.

[Fix Direction]

"Before Use" occurs before a Clash. "Before Attack" occurs after the Clash has ended, just before the attack itself begins.

Changing the effect's activation timing to match the current "Before Attack" text could cause the following issues:
1. Allies could no longer use the Tremor inflicted by "Judgment!" as a conditional to satisfy Power increase conditions.
2. "Judgment!" would not activate if an ally lost the Clash and could not attack.
3. "Judgment!" could no longer Stagger an enemy before the ally's Clash.

In short, changing the effect to match the current text in all cases could weaken the Identity. We will therefore retain the existing ""Before Use" activation timing and correct the missing activation cases and incorrect conditions.

[Scheduled Changes]

1. The Passive will activate before an allied Le Noir Identity uses a Counter Skill, Clashable Counter Skill, or Attack Skill converted from a Defense Skill at Combat Start.

2. The Passive's activation will be checked against the Skill an ally actually uses, rather than only the Skill assigned during the Chaining Phase.
- This will allow the effect to activate when another allied Le Noir Identity uses an Attack Skill or Counter Skill against an enemy through an Assist Attack, Passive effect, or other means.
- The effect will not activate if the said ally is immobilized/unable to act and cannot use the Skill.

3. The Passive text will be revised to clarify its activation timing and which Skills qualify.
- Before: Before Attack of another "Le Noir" allied Identity on an enemy, this unit uses "Judgment!" Skill as an Unopposed Attack against the main target (once per turn)
- After: Before another "Le Noir" allied Identity uses Attack Skills or Counter Skills on an enemy, this unit uses "Judgment!" Skill as an Unopposed Attack against the main target (once per turn)

We apologize for the confusion caused by these repeated corrections to the Identity's performance and behavior. We recognize that we have failed to reflect the design changes accurately in both the implementation and the text, and failed to catch those errors during review.

Going forward, we will improve communication during development, verify that implementation and text agree, and strengthen our review of individual cases, including Defense Skills, activation timing, and whether a unit is able to act.

We sincerely apologize for the inconvenience.
