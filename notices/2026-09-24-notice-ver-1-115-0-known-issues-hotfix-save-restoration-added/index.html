    Notice: Ver. 1.115.0 Known Issues Hotfix & Save Restoration Added

    September 24, 2026

    Hello, this is Project Moon.

    A hotfix for some of the known issues in ver. 1.115.0, shared in our last update, will be deployed.

    We will also implement a "Save Restoration" function to help users resolve any soft-locking issues that may occur or have occurred.

    Please refer to the information below.

    [ Hotfixes ]

    ▶ Fixed an issue where maps on certain floors would be partially cropped when playing the game at a resolution with a narrower aspect ratio

    ▶ (The Symbolic) Fixed an issue where entities belonging to a certain faction could neither attack nor be attacked

    ▶ Fixed typos and text errors identified following the update

    ▶ (The Symbolic) Fixed an issue where unintended text would be displayed when interacting with a certain object during the early portion of the content

    ▶ Fixed an issue where certain unintended text would be displayed in the main story

    ▶ Fixed an issue where the Panic-state flavor texts were missing for certain units

    ▶ (The Symbolic) Prevented certain units from becoming killable until a certain quest is completed

    ▶ (The Symbolic) Fixed an issue where quest progression would become impossible if a certain unit was defeated first while the quest is in progress

    ▶ (The Symbolic) Fixed an issue where, under certain conditions, the screen would fade to black, and the player would lose all held Items

    [Save Restoration Function]

    A "Save Restoration" function will be added to quickly resolve any quest soft-locking issues in Canto X.
    Using this function will allow the user to reload the game to the latest savepoint.

    <How-to>

    - Settings - Select the "Restore Save" button at the bottom of the Sisyphe tab.
    - You may preview your progress at that savepoint before choosing to restore to that point.

    <Notes>

    - The Save Restoration function is a temporary measure to resolve any existing progression-blocking issues.
    - Please use this function only when a soft-locking issue has occurred; restoring a save when the game's functions are working as intended may cause other issues.
    - The Save Restoration function may not be able to resolve the issue if the user continues to play in the same save even after an issue has occurred.
    - The Save Restoration function loads previous data from the same run. Therefore, the user will not be able to restore the save after pressing either the "Liquidation (reset)" or the "Close Down (hard reset)" button.

    [ Hotfix ETA ]

    - Sep. 24th (Thu) 20:30 (KST)
    - There may be a delay of approximately 10 minutes.

    ※ The Hotfix will be deployed upon restarting the game, and does not require a separate client update. However, please note that additional in-game downloads may occur.

    We sincerely apologize for the inconvenience.
