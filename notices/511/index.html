2025, Dec. 24th Scheduled Update Notice

December 22, 2025

Greetings, Dear Manager.

The server will enter scheduled maintenance from
10:00 [AM] through 12:00 [PM] on Dec. 24th, 2025 (KST).

Please make note of the maintenance schedule; we recommend
that you refrain from entering combat or making in-app
purchases and close the application before maintenance
begins so that no data is lost.

Please refer below for details about the update.

Notice : Scheduled Update Date Changes & Weekly Rewards (Time in KST)

Due to Christmas and New Year's holidays in 2025, Dec. 25th,
and 2026, Jan. 1st, respectively, Scheduled Updates
will not be deployed on Thursdays for those weeks.
Instead, Scheduled Updates will be deployed on
Wednesday, a day earlier than our usual time.

※ Scheduled Update Date Changes
- Before : 2025, Dec. 25th (Thu) 10:00
- After : 2025, Dec. 24th (Wed) 10:00

- Before : 2026, Jan. 1st (Thu) 06:00
- After : 2025, Dec. 31st (Wed) 06:00

While Season 7 Update and Season 7 Limbus Pass will be deployed
on Dec. 31st (Wed), Weekly Missions & Mirror Dungeon Weekly Bonus
resets will occur on Jan. 1st (Thu) 06:00 (KST), the same time as usual.

In order to minimize confusion, we have prepared
the following chart to determine which Season’s Pass EXP
will be obtainable between Dec. 25th 12:00 ~ Jan. 8th 06:00 via
Weekly Missions and Mirror Dungeon Weekly Bonuses.

[ 12/25 12:00 ~ 12/31 05:59(KST) ]

- Weekly Missions : Clearing Weekly Missions grants Season 6 Pass EXP
- Mirror Dungeon Weekly Bonuses : Using Weekly Bonuses grants extra Season 6 Pass EXP

[ 12/31 12:00 ~ 1/1 05:59(KST) ]

- Weekly Missions : Weekly Mission Reset - Yes
Clearing Weekly Missions grants Season 7 Pass EXP
- Mirror Dungeon Weekly Bonuses : Weekly Bonus Reset - No
Using Weekly Bonuses grants extra Season 7 Pass EXP

[ 1/1 06:00 ~ 1/8 05:59(KST) ]

- Weekly Missions : Weekly Mission Reset - Yes
Clearing Weekly Missions grants Season 7 Pass EXP
- Mirror Dungeon Weekly Bonuses : Weekly Bonus Reset - Yes
Using Weekly Bonuses grants extra Season 7 Pass EXP

Major Changes

► Season 6 Battle Pass end date added

Bug Fixes and Improvements

► Fixed an issue where incorrect damage number would
additionally be displayed when 'Sinking Deluge' is triggered
※ Actual damage and cumulative damage values were functioning
normally. Only the displayed damage value has been corrected.

► Fixed an issue where incorrect damage forecasts were displayed
when enemies (inflicted with damage-lowering E.G.O or Skill effects
such as Power Down or Paralyze) used Skills
with the effect "fix damage dealt to 0 / deal 0 damage"
※ This issue was addressed with the December 11 Scheduled
Update; however, an additional fix was implemented
as the issue persisted during Unopposed Attacks where
Clashes do not take place.

► Fixed an issue where, under specific conditions,
certain voicelines and dialogue text did not match after
the lobby illustration was set to Wild Hunt Heathcliff

► (EN Only) Added missing translation for one of
N Corp. E.G.O::Fell Bullet Yi Sang's voicelines
※ Relevant voiceline : "Idle" voiceline

► (Steam) (EN, JP only) Fixed an issue where no pop-up text was
displayed when prompting users to run Steam verify integrity
check due to missing resources

► (iOS) Fixed an issue where "Error Code: 13004" would occur
on game launch after an App Store purchase is
refunded after being put on hold

Maintenance & Application Update Compensation

- Recipients : All users whose game accounts were created before

- When : After Dec. 24th, 2025 (Wed) 12:00 (KST)

Notes

- Forcibly shutting down the game while it is downloading resources may cause the download to fail, so please be careful not to close the application during the download.
- You will not be able to play <Limbus Company> during maintenance. Please understand.
- The maintenance schedule may suddenly change depending on the status of maintenance. If such a change occurs, we will let you know in a follow-up notice.
- A resource download may be prompted after the build update. If you're using a mobile device, it is recommended to proceed with a Wi-Fi connection.
- If you're playing with a guest account, we recommend that you link your account with other platforms to prevent possible account loss.
- The maintenance compensation will be provided once per account. Please note that the distribution may be slow due to network delays or other causes.
- The update gifts are valid to claim for 7 days. Please redeem them within this timeframe.

Thank you.
