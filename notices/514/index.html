    Notice: Known Issues in Dec. 31st, 2025 Scheduled Update

    December 30, 2025

    Hello, this is Project Moon.

    We have identified the following issues in today's Scheduled Update, updated Dec. 31st, 2025.

    Currently, we are investigating the following issues; we will inform you via a separate notice for their causes, solutions, and possible Hotfix ETA.

    Please continue reading for more information.

    [Known Issues]

    ▶ An issue where, when progressing through the combat Encounters of the Main Story, using the "Retry Stage' function to clear a Stage causes the game to skip the post-battle story

    ▶ An issue where, in a certain Stage and under certain conditions, using Lobotomy E.G.O::Magic Bullet Outis's Skill 3 causes the game to softlock

    ▶ An issue where, in Limbus Pass Package purchase confirmation pop-up window, the Identity Level Boost Ticket appears as "Identity Level Boost Ticket V" and not "Identity Level Boost Ticket VI" as it should be
    ※ This is a text-only correction; purchasing this package will yield "Identity Level Boost Ticket VI" as intended.

    ▶ (EN Only) An issue where, in The Index Proselyte:【Paper Slip】Faust's Skill description, a certain instance of "Poise" was mislabeled as "Breath"
    ※ "Breath" will be replaced with "Poise."

    ▶ An issue where, in certain device, Stage 9-3 appears blurry

    We sincerely apologize for the inconvenience.
