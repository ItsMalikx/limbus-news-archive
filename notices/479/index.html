E.G.O Gift Effect Adjustments
-----------------------------

1. Now, any HP healing effects from E.G.O Gifts will no longer
be affected by HP Healing Boost or HP Healing Down effects.

[ Affected E.G.O Gifts (16 Gifts) ]
Resolution, Phlebotomy Pack, First-aid Kit, Painkiller, Uncapped Defibrillator, Compression Bandage, Trash Crab Brain Wine, Canned Ice Cream, Crystallized Blood, Perpetual Generator Servos, Magical Girl's Lovely Gift, Emergency Investigator Badge, Virtue - Ren (仁), Cultivation: Cut, File, Carve, Polish, Bloodflame Sword, The Family's Resentment

2. E.G.O Gift Resolution's effects and description will be changed.
- Before : Shi Assoc. Identities' HP gets capped to 75% of Max HP. In return, take 50% less damage and receive 50% reduced heal(activates immediately upon entering an Encounter).
- After : Shi Assoc. Identities' HP gets capped to 75% of Max HP. In return, take 50% less damage and receive 50% reduced heal. (activates immediately upon entering an Encounter; except healing from E.G.O Gifts)
- New Effect : Shi Assoc. Identities gain 1 Slash Power Up and 1 Slash DMG Up at every Turn Start.

3. E.G.O Gift Bloodflame Sword's description will be changed.

- Before : For Heishou Pack - You Branch Identities: HP gets capped to 49% of Max HP. In return, take 50% less damage and receive 50% reduced heal
- After : For Heishou Pack - You Branch Identities: HP gets capped to 49% of Max HP. In return, take 50% less damage and receive 50% reduced heal (except healing from E.G.O Gifts)

Bug Fixes & Improvements
------------------------

► Fixed an issue where, among Unbrilliant Glory Gregor's Awakening Skill effects, "[After Attack] Heal 5 SP for every target that was Staggered or killed due to this Skill's damage (max 25)" only detected a single target at the "After Attack" activation timing

► Fixed an issue where, under specific conditions, using a Defense Skill as N Corp. E.G.O::Contempt, Awe Ryoshu could cause the game to softlock

► Fixed an issue where To Remain Oneself [宁作吾] Hong Lu's Awakening Skill had a misaligned VFX trace in the final slash

► Fixed an issue where, in a single Encounter, if the player chooses the combination of same Identity and the same Skill for multiple different Choice Events, the results of the first Choice Event check would be replicated on every subsequent Choice Events

► Fixed an issue where the battle animation doesn't end when both enemy and allied units are immobilized, softlocking the player

► Fixed an issue where, in "N Corp. New League of Nine Littérateurs" MD EXTREME Theme Pack, getting inflicted with "Binding Technique" would last for the whole Encounter

► Fixed an issue where being targeted by enemy Skills with 2+ Atk Weight caused 2 or more Clash arrows to appear

► Adjusted so that, in Stage 6-48, the option pop-up would not appear under certain circumstances

► Fixed an issue where, in Refraction Railway Line 5 Section 3 Wave 1, a single unit would appear as though there are many

► Fixed an issue where certain UI elements would linger when the player presses the ESC key to exit the window while opening the inventory

► Fixed an issue where, in certain conditions, using Takeoff Module - ID Uptie in the inventory would play the Lobby Identity's voiceline

► Fixed an issue where an unobtainable LIMBUS PASS Ticket Deco does not have a black-and-white filter over it

► Fixed an issue where, in Mirror Dungeon E.G.O Gift Fusion UI, having 99.99% Keyword Fusion rate would have the text escape the text box

► Fixed an issue where, if the player loads into the Shop UI due to insufficient Extraction resources, then closes the Shop UI, the bottom menu UI becomes obscured
