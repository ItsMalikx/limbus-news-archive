    (AOS, iOS) Notice: Version 1.88.1 Update to Address Issues From Oct. 9th Update

    October 9, 2025

    Hello, this is Project Moon.

    We have deployed the AOS, iOS Platform 1.88.1 Version update that fixes the issues mentioned in our previous notice.

    Please close the game, update the game client, and you can play the game without the issues introduced with Version 1.88.0.

    Please continue reading for more information.

    [ Fixed Issue ]

    An issue where, after the Oct. 9th Scheduled Update, pressing the button to enter Combat Phase may cause the game to lag

    [ Version Update ETA ]

    - After 10.10(FRI) 18:00(KST)
    - Please note that there may be a 10-minute margin of error to the ETA.

    Please note that a properly updated version of the game will show Version number "1.88.1" at the bottom right corner of the game window on its title screen.

    If the Market Store does not display an option to update the game, please try again at a later time, as deployment times may vary depending on your device settings.

    Once again, we sincerely apologize for the inconvenience.
