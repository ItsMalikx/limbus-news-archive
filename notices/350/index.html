Bug Fixes & Improvements

► Adjusted Kurokumo Clan Captain Ishmael's 'Cloud Workshop Blade' Support Passive description
- Before: 1 ally with the fastest Speed inflicts +1 more Bleed
- After: 1 ally with the fastest Speed inflicts +1 more Bleed Potency or Count with Skill and Coin Effects against enemies
※ We have adjusted the description to be clearer as its previous description was too vaguely written.
The actual function of the Passive hasn't changed; this is a description-only change.

► Fixed an issue where, if a Floor Theme exclusive E.G.O Gift was included in 2 or more Theme Packs, there were situations in which 'Keyword Gift Rate Up' effect did not activate for them in the Shops' E.G.O Gift Fusion function

► Fixed an issue where Identities or Peccatula Invidiae that were killed at Turn Start would still activate their Combat Passives

► Fixed an issue where HP Healing Boost/Down effects did not work properly against Peccatula Invidiae in Focused Encounters

► Fixed an issue where conditional Power boost effects were unconditionally applied when calculating Clash outcome predictions
※ Relevant effects: Coin Power +M for every N [Status Effect] on the target

► Fixed an issue where 'The Finale' Skill of the 7-34 Stage Boss had an incorrect description
- Before: [After Attack] Lose SP equal to the amount of Bloodfeast consumed by this Skill
- After: [After Attack] Reduce SP to -45
※ Because our difficulty testing was done based on the actual behavior of the Skill, changing it to match the texts now will may change the player experience; therefore, we have adjusted the text it to match the actual effects.

► Added new effects related to Stage 7-34 Boss 'Hurting Teddy Bear'

► Fixed an issue where certain Canto 7 enemy Skill effects had incorrect descriptions
- Fix Direction: Change the texts to match the actual behavior
- Relevant Skills: Let's All Match Our Steps, Dance!, Hardblood Power Unfurling
※ Because our difficulty testing was done based on the actual behavior of the Skill, changing it to match the texts now will may change the player experience; therefore, we have adjusted the text it to match the actual effects.
