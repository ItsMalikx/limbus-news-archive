2026, Aug. 13th Scheduled Update Notice

August 12, 2026

Greetings, Dear Manager.

The server will enter scheduled maintenance from 10:00 [AM] through 12:00 [PM] on Aug. 13th, 2026 (KST).

Please make note of the maintenance schedule; we recommend that you refrain from entering combat or making in-app purchases and close the application before maintenance begins so that no data is lost.

Please refer below for details about the update.

Bug Fixes & Improvements

► Fixed an issue where, when "Dawn Office Fixer Faust" Support Passive is active, the game would become unresponsive after all allies are killed in a specific circumstance

► (EN Only) Fixed an issue where the "Time Moratorium" Keyword had an incomplete description
- Before: If there is only 1 Count left of this effect, the effect triggers Tremor Burst after dealing (100 + (Stack x 15))% of stored damage as Sloth damage
- After: If there is only 1 Count left of this effect, the effect triggers Tremor Burst "(Stack) times" after dealing (100 + (Stack x 15))% of stored damage as Sloth damage
※ This is a description-only fix; the effect is working as described in the "After".

► (JP Only) Fixed a typo in an ally buff obtainable after completing a Cycle in "Refraction Railway Line 2 BokGak"
- Before: ○○属性スキルの与・被ダメージ量 +XX%
- After: ○○属性スキルの与ダメージ量 +XX%

► Fixed an issue where, when the user selects the EXP Luxcavation menu after completing a Thread Luxcavation, the UI would scroll to a specific point regardless of the user's unlock status

► (EN Only) Standardized the Manager Ticket phrase format in case of multiple possible grammar forms
※ E.g.: When there are two possible variations of the indefinite article (A or An)
- Before: Both "(A)an" and "(A/An)" were used
- After: Standardized as (A/An)

► (Mobile Only) Fixed an issue where Yi Sang's mugshot image in "Theater - Identity Stories" was flipped horizontally

► (JP Only) Fixed an issue where, in Stage 7-36, the BGM lyric texts appeared in unintended colors

Maintenance & Application Update Compensation

- Content : Lunacy x300
- Recipients : All users whose game accounts were created before Aug. 20th, 2026, 10:00 AM (KST)
- When : After Aug. 13th (Thu), 2026, 12:00 (KST)

Relevant Compensation can be claimed until Aug. 20th (Thu), 2026, 10:00 (KST) via the in-game Mailbox (mail available for 7 days).
