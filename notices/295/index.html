Major Changes

1. Added an indicator for the number of Waves or number of enemies in a single Encounter
An indicator alternating between displays for the number of Waves or the number of enemies has been added to the top left corner of the screen. Press the indicator to toggle between a counter for Waves and a counter for the number of remaining enemies.

Bug Fixes & Improvements

► Fixed an issue where the game would sometimes softlock in a Clash against an enemy Part in a Focused Encounter

► Fixed an issue where, under certain circumstances, Wild Hunt Heathcliff's Skill 3 'Lament, Mourn, and Despair' would only have a single Coin instead of two

► Fixed an issue where the game would sometimes softlock and fix the Skill Power to 0 upon using a Skill in Stages against Peccatulum Invidiae

► Fixed an issue where the in-game UI functions incorrectly when, in Story Dungeons, viewing effect tooltips in the E.G.O Gift Acquisition pop-up windows would cause the game to softlock

► Fixed an issue where, under certain circumstances, Thread Luxcavation Daily Bonus Rewards would show an abnormal amount of Threads
※ This is a visual-only issue; the actual rewards were acquired normally.

► Fixed an issue where consecutively Threadspinning an E.G.O in the Passives tab of E.G.O Detailed Information Window caused the "Threadspin" button to turn into an "Uptie" button

► Fixed an issue where the Sapling of Light UI did not load correctly

► Fixed an issue where the Unbreakable Coin effect icon had an incorrect color
- Before : Grey Coins
- After : Red Coins

► (EN Only) Rephrased Cinq South Section 4 Outis' Defense Skill 'Retraite' for better readability
- Before : If this unit's Speed is higher than the target's, Coin Power +1 for every Speed difference (Coin Power +1 for every 1 Speed difference; max 3)
- After : If this unit's Speed is faster than the target's, gain Coin Power based on Speed difference (Coin Power +1 for every Speed difference; max 3)

► (EN Only) Fixed typos and grammatical errors for Zwei West Section 3 Ishmael's Voicelines and Uptie Story
(1) Typos in certain Voicelines
(2) Grammatical errors in the Uptie Story

► Fixed an issue where, in the Extraction History UI, an obtained Identity's CG art shows up as the pre-uptie art
