2024, Oct. 31st Scheduled Update Notice

2024-10-28

---------------------------------------

Greetings, Dear Manager.

The server will enter scheduled maintenance from 10:00 [AM] through 12:00 [PM] on Oct. 31st, 2024 (KST).

Please make note of the maintenance schedule; we recommend that you refrain from entering combat or making in-app purchases and close the application before maintenance begins so that no data is lost.

Please refer below for details about the update.

New Content
-----------

1. New Target Extraction - [The Priest of La Manchaland Gregor] (10/31 12:00 ~ 11/14 10:00 (KST))
The following Identities will have increased odds of extraction
- 3★ : The Priest of La Manchaland Gregor

2. Target Extraction [Rodion] (10/31 12:00 ~ 11/14 10:00 (KST))
Extraction rate increases for the following Identities and E.G.O
- E.G.O [HE] : Pursuance Rodion
- 3★ : Devyat' North Section 3 Rodion, Liu South Section 4 Director Rodion, Dieci South Section 4 Rodion, Rosespanner Workshop Rep Rodion, Kurokumo Clan Wakashu Rodion
- 2★ : T Corp. Class 2 Collection Staff Rodion, Zwei South Section 5 Rodion, N Corp. Mittelhammer Rodion, LCCB Assistant Manager Rodion
- 1★ : LCB Sinner Rodion

3. New Identity Added
The following Identity is added to the list of extractable Identities.
- 3★ : The Priest of La Manchaland Gregor

Bug Fixes & Improvements
------------------------

► Fixed an issue where chaining a Skill with 'Clashable Guard' type Guard Skills displayed an abnormal Clash Value

► Fixed the progression blocker where the game would softlock into a black screen in the middle of a Story Dungeon
※ We have addressed the direct cause of the issue, which occurred when progressing through the dungeon with a Friend Support Identity that the player did not own.

► Fixed issues related to the Sapling of Light ability
(1) An issue where, when the E.G.O Skills would activate as Corrosion Skills due to issues such as SP, the unused E.G.O resources required for Overclock would be refunded to the player
(2) An issue where the game would softlock when the player 1) activated the E.G.O Skill, 2) ended the turn, then 3) lost enough SP to corrode

► Added the missing Passive to certain entities in the Stage 7-36 Boss Encounter
※ Relevant Effects: Withered

► Fixed an issue where the Clashable Guard VFX/text when winning a Clash with a Clashable Guard against a certain Boss in Stage 7-36 was missing
※ This is a visual-only issue; the effect is working as intended

► Adjusted the description for Stage 7-36 Boss, where a certain effect was written as "End Combat Phase"
- Before : [After Attack] End Combat Phase
- After : [After Attack] Ends this turn

► Fixed two issues regarding Stage 7-36 Abnormality boss 'Rose Hunter'
(1) An issue where the Sinners would be placed at incorrect spots on the field
(2) An issue where, under certain circumstances, the Barbed Lasso(summoned unit) would remain even after destruction

► Added Trait Keywords to certain units in Stage 7-36 Boss encounter

► Fixed an issue where the Sinners would be placed at incorrect spots on the field in Stage 6-41

► Fixed an issue where the 'Legend' button would not work as intended in the Mirror Dungeon node selection screen

► Fixed an issue in the Story Dungeon where viewing the Stage Info tab from a specific zone would cause the camera to become unresponsive

► (EN, JP Only) Fixed an issue where the E.G.O Gift name's Font & Font Material would not load in the UI that appears after gaining an E.G.O Gift due to Choice Events

► Addressed the issue where a particular in-game cutscene for 7-36 Boss Encounter would not work properly on lower-end devices

► (EN Only) Fixed grammatical errors present in the new Announcers' dialogue

Known Issues
------------

► An issue where the Sinner Don Quixote could be slotted in as a Backup Unit in Stage 7-36
※ Our intent was to have Sinner Don Quixote mandatorily deployed at all times in the relevant Encounter, but in the current version, she can be slotted in as a Backup Unit. Please note that slotting in Sinner Don Quixote as a Backup Unit could cause issues with progressing through the fight.

► An issue where certain Sinners could, under certain circumstances, randomly appear in a cutscene in Stage 7-36 Boss Encounter

► An issue where, under rare circumstances, the game would softlock in the Stage 7-36 Boss Encounter

► An issue where the Status Effect damage text would load twice after Clashing with a certain boss in Stage 7-36
※ This is a visual-only issue; the effects are working as intended

► An issue where an incorrect combat stage image would load when using an E.G.O below Threadspinning Tier 3

Maintenance & Application Update Compensation
---------------------------------------------

- Content : Lunacy x300
- Recipients : All users whose game accounts were created before 10:00 Nov. 7th, 2024 (KST)
- When : After Oct. 31st, 2024 (Thu) 12:00 (KST)
- Can be claimed once per account

Maintenance Compensation can be claimed until Nov. 7th (Thu) 2024, 10:00 (KST) via the in-game Mailbox. (Mail available for 7 days)

Notes
-----

- Please update your game client to the newest version on the respective store (Google Play/App Store/Steam).
- Forcibly shutting down the game while it is downloading resources may cause the download to fail, so please be careful not to close the application during the download.
- You will not be able to play <Limbus Company> during maintenance. Please understand.
- The maintenance schedule may suddenly change depending on the status of maintenance. If such a change occurs, we will let you know in a follow-up notice.
- A resource download may be prompted after the build update. If you're using a mobile device, it is recommended to proceed with a Wi-Fi connection.
- If you're playing with a guest account, we recommend that you link your account with other platforms to prevent possible account loss.
- The maintenance compensation will be provided once per account. Please note that the distribution may be slow due to network delays or other causes.
- The update gifts are valid to claim for 7 days. Please redeem them within this timeframe.

Thank you.
