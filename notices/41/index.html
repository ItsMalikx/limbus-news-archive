Game Security Settings Adjusted

April 9, 2023

Greetings, dear manager.

A number of adjustments were made during the emergency maintenance performed between 2023 Apr 07 19:40 ~ 20:20 (KST) to adjust the intensity of security measures as previously announced.

[Adjustments]
- App security restraints relaxed
- Fixed an issue where the game could not be played if certain applications are installed on the device
- Restored support for certain emulators
- Fixed an issue where certain developer mode settings prevented access from the game
- Fixed an issue where the game could not be accessed in a work profile environment

We apologize for the inconvenience caused by security-related issues.

Thank you.
