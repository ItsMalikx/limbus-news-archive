Pre-fix Notice: Game Freezing Issues After the 5/28 Scheduled Update

2026-06-02

Hello, this is Project Moon.

Following the game update on May 28th, 2026, we have identified an issue on some devices where the game freezes during combat, blocking progression, or crashes unexpectedly.

This issue has been confirmed to occur on certain devices, and we have found that disabling the post-processing option may partially mitigate the problem.

At this time, the fix and deployment schedule has not yet been confirmed.
We will inform you again via a separate notice once the fix to the issue becomes available.

Until the issue is resolved, we kindly ask that you change the in-game setting under Settings → Graphics → Post-processing to "Off" before playing.

We sincerely apologize for the inconvenience.

Thank you.
