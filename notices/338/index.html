Major Changes

1. (Android, iOS) Added maxed out Enkephalin notification settings

You can turn the function ON or OFF by going to [Settings] → [General] → 'Notification Settings'

※ This function works only when you enable the Notification function in your device settings.
※ There may be a delay depending on the settings or the processor of each device.

2. Added a warning note to certain E.G.O in the extraction menu

A warning has been added to the top right corner of the extraction menu for certain E.G.Os with Passives that either disable or weaken the effects of E.G.O Gifts when used in tandem

3. Added a limiter to how many items can be used at once in the inventory menu
We have limited the number of items that can be used at once to 400 items. This was done to prevent the unintended or accidental usage of too many items at once.

4. New Trait Keywords added
LCB, LCC, LCE Faction Keywords have been added.

Bug Fixes & Improvements

► Fixed an issue where clearing Main Story 7-30 did not give out Account EXP and Identity EXP
- Before: 0 Account EXP, 0 Identity EXP
- After(intended): 20 Account EXP, 600 Identity EXP
※ We have identified a data error regarding the EXP rewards for completing Main Story 7-30. A hotfix regarding this issue will be deployed on Jan. 21st (TUE) 16:00 (KST).

The hotfix will be deployed without a separate client update; once the hotfix has been deployed, users should be able to receive their Account EXP and Identity EXP as intended upon clearing Main Story Stage 7-30.

On the Jan. 23rd (THU) Scheduled Update, we intend to compensate managers who did not receive the above rewards with Enkephalin Modules. We sincerely apologize for the inconvenience.

► Added effect limitation text for the E.G.O Gift 'Nebulizer'
※ Added Text : - [Cannot Stack] When Thoracalgia Ryōshū E.G.O Passive 「Breath」 activates, this effect does not activate

► Fixed an issue where the Full-Stop Office Fixer Heathcliff's 'Target Spotted' effect could activate even when Corroded by E.G.O

► Fixed an issue where the Full-Stop Office Rep Hong Lu's 'Melee Support' effect could activate even when Corroded by E.G.O

► Deployed preventative measures to make sure that The Manager of La Manchaland Don Quixote's Passive 'Bloodfeast' always works as intended
※ Relevant effects: When using 'Variant Sancho Hardblood Arts 6 - Whip', HP cannot drop below 1 due to Bleed damage.
※ The actual effect itself has not changed.

► Adjusted certain text descriptions for a Boss appearing in Stage 7-36
※ Reasoning : We have identified an issue where the actual effects of each Skill did not match the text descriptions. So, we have adjusted the text to match the actual effects.
※ The actual effects have not been changed.
(1) A certain Skill effect description changed
- Before : [Combat Start] Consume Up to (45 - current SP) Bloodfeast to heal up to 45 SP
- After : [On Use] Consume up to (45 - current SP) Bloodfeast to heal up to 45 SP
(2) A certain Passive effect description changed
- Before : Turn End: for every 10% missing HP, gain 1 Offense Level Up
- After : Said effect description has been deleted

► Fixed an issue where, when the Mirror Dungeon Abnormality Faelantern's "Body" appears after meeting a certain condition, it appears Staggered

► Fixed an issue where certain VFX did not load for Stage 5-32 story scene

► (EN Only) Adjusted the translation of the Choice Event for the Abnormality - Sleeping Bag of the Olden Days for accuracy
